**Step 2: Define the input string and self-edit rules**
```python
input_string = "I am struggling with self-doubt."
self_edit_rules = [
    {"pattern": r"\bstruggling\b", "replacement": "working on"},
    {"pattern": r"\bdoubt\b", "replacement": "confidence"}
]
```
In this step, we define the input string and a list of self-edit rules. Each rule consists of a regular expression pattern to match and a replacement string.

**Step 3: Apply self-edits using a recursive function**
```python
def apply_self_edits(input_string, self_edit_rules):
    if not self_edit_rules:
        return input_string

    rule = random.choice(self_edit_rules)
    pattern = re.compile(rule["pattern"])
    replacement = rule["replacement"]

    new_string = ""
    for word in input_string.split():
        match = pattern.search(word)
        if match:
            new_word = word[:match.start()] + replacement + word[match.end():]
            new_string += new_word + " "
        else:
            new_string += word + " "

    return apply_self_edits(new_string.strip(), self_edit_rules[:-1])
```
In this step, we define a recursive function `apply_self_edits` that applies each self-edit rule to the input string. The function selects a random rule from the list, compiles the pattern, and replaces matching words with the specified replacement string.

**Step 4: Run the self-edits and print the result**
```python
result = apply_self_edits(input_string, self_edit_rules)
print(result)
```
Finally, we run the `apply_self_edits` function with our input string and print the resulting output.
