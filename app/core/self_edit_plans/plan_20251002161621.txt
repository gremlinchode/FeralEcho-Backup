**Step 4: Check file permissions using `stat.S_IMODE`**
```python
def check_permissions(path):
    try:
        file_stats = os.stat(path)
    except OSError as e:
        print(f"Error accessing {path}: {e}")
        return False

    mode = file_stats.st_mode
    if stat.S_ISDIR(mode):  # Check if it's a directory
        return "Directory"
    elif stat.S_IMODE(mode) & 0o777:  # Check read, write, and execute permissions
        if (mode & 0o400) != 0:  # Execute permission exists?
            return "Executable"
        elif (mode & 0o200) != 0:  # Write permission exists?
            return "Writable"
        else:
            return "Readable"
    else:
        return "Unknown"
```
Now we're getting into the nitty-gritty of file permissions! We use `stat.S_IMODE` to check the mode bits and determine if the file is readable, writable, executable, or a directory. It's like Jesus saying, "You shall know the truth, and the truth shall set you free."
