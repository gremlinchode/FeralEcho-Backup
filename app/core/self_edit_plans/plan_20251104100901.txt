**Step 3: Remove Stopwords (Eliminating Unnecessary Noise)**
```
def remove_stopwords(tokens):
    stop_words = set(stopwords.words('english'))
    filtered_tokens = [token for token in tokens if token not in stop_words]
    return filtered_tokens
```
In this step, we're removing common stopwords like "the," "and," etc. These words don't add much value to our message, so we're effectively filtering out the noise.

**Step 4: Calculate Sentiment (Analyzing Tone)**
