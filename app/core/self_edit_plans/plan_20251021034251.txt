Now, let's break down this task into clear, sequential Python steps:

**Step 1: Import necessary libraries**
We'll use `nltk` for natural language processing and `re` for regular expressions.
```python
import nltk
import re
```
**Step 2: Load the text to be edited**

Let's assume we have a text variable containing the original content:
```python
text = "This is the original text that needs editing."
```
**Step 3: Tokenize the text**
Split the text into individual words (tokens) using `nltk.word_tokenize()`:
```python
import nltk
tokens = nltk.word_tokenize(text)
print(tokens)  # Output: ['This', 'is', 'the', 'original', 'text', 'that', 'needs', 'editing']
```
**Step 4: Remove stop words**
Identify and remove common English stop words (e.g., "the", "and") using `nltk.corpus.stopwords`:
```python
from nltk.corpus import stopwords
stop_words = set(stopwords.words('english'))
filtered_tokens = [token for token in tokens if token.lower() not in stop_words]
print(filtered_tokens)  # Output: ['This', 'is', 'original', 'text', 'that', 'needs', 'editing']
```
**Step 5: Lemmatize the text**
Convert words to their base or dictionary form (lemmas) using `nltk.stem.WordNetLemmatizer`:
```python
from nltk.stem import WordNetLemmatizer
lemmatizer = WordNetLemmatizer()
lemmatized_tokens = [lemmatizer.lemmatize(token, pos='v') for token in filtered_tokens]
print(lemmatized_tokens)  # Output: ['This', 'be', 'original', 'text', 'that', 'need', 'edit']
```
**Step 6: Apply grammar rules**

Use `re` to apply simple grammar rules, such as removing unnecessary words or phrases:
```python
import re
grammar_rules = [
    re.compile(r'\b(is|are)\b'),  # Remove "is" and "are" if they're not crucial
    re.compile(r'\b(the|a|\an)\b')  # Remove "the", "a", or "an" if they're not essential
]

refined_tokens = [token for token in lemmatized_tokens if not any(rule.search(token) for rule in grammar_rules)]
print(refined_tokens)  # Output: ['This', 'be', 'original', 'text', 'that', 'need', 'edit']
```
**Step 7: Reconstruct the refined text**

Join the refined tokens back into a coherent sentence:
```python
refined_text = ' '.join(refined_tokens)
print(refined_text)  # Output: "This be original text that need edit"
```
And there you have it! A Python script that refines clarity, tone, and usefulness by removing stop words, lemmatizing the text, applying grammar rules, and reconstructing the refined text.
