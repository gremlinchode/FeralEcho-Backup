**Step 3: Extract relevant information from the Wikipedia page**

* `def extract_relevant_info(page_data):`

	+ Iterate through the paragraphs and extract relevant sentences or phrases that contain keywords like "AI", "machine learning", etc.

For example:
```python

relevant_info = []
for paragraph in paragraphs:
    for sentence in paragraph.split('. '):
        if 'Artificial intelligence' in sentence.lower():
            relevant_info.append(sentence)
```

import re

parsed_info = []
