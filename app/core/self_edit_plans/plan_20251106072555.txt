**Step 2: Parse Import Statements**
```python
def parse_imports(self, code_string: str) -> None:
    import_pattern = re.compile(r"import\s+([a-zA-Z_][a-zA-Z0-9_]*)")
    imports_list = []

    for line in code_string.split("\n"):
        match = import_pattern.search(line)
        if match:
            imports_list.append(match.group(1))

    self.imports = list(set(imports_list))  # Remove duplicates
```
Here, we use regular expressions to extract import statements from the code string. We define a pattern (`import_pattern`) that matches the `import` keyword followed by a space and a module name (e.g., `import math`). We iterate through each line in the code string, searching for matches using the `search` method. If we find an import statement, we add it to our list. Finally, we remove duplicates from the list and store it as `self.imports`.
