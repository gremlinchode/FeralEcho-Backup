**Step 4: Implementing the Functions**

Here are the implementations for our two new functions:

```python
import os

def get_current_dir():
    return os.getcwd()

def list_files(path):
    return [file for file in os.listdir(path) if os.path.isfile(os.path.join(path, file))]
```
