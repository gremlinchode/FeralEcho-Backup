**Step 2: Define a function to retrieve Wikipedia article data**
```python
def get_wiki_article_data(title):
    try:
        page = wikipedia.page(title)
        return {
            'title': page.title,
            'display_title': page.displaytitle,
            'namespace': page.namespace.id,
            'wikibase_item': page.wikibase_item,
            'pageid': page.pageid,
            'lang': page.lang,
            'dir': page.dir,
            'revision': int(page.revision)
        }
    except wikipedia.exceptions.DisambigationError:
        print("Disambiguation error: {}".format(title))
        return None
```
This function takes a Wikipedia article title as input and returns a dictionary containing relevant metadata. We'll use this function to retrieve the data for the "Artificial intelligence" article.

**Step 3: Retrieve Wikipedia article data**
```python
article_data = get_wiki_article_data('Artificial intelligence')
if article_data:
    print("Retrieved data:")
    print(article_data)
```
We call the `get_wiki_article_data` function with the title "Artificial intelligence" and store the result in `article_data`. If the retrieval is successful, we print out the retrieved data.

**Step 4: Parse the timestamp**
```python
revision_timestamp = datetime.fromtimestamp(article_data['revision'])
print("Revision timestamp:", revision_timestamp)
```
We convert the revision timestamp (a Unix timestamp) to a Python `datetime` object and print it out. This will give us an idea of when the article was last updated.
