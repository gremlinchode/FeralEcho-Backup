```python
def generate_random_data(size):
    return [random.randint(0, 100) for _ in range(size)]
```
**Step 2: Define a class to analyze the data**
Let's create a class called `DataAnalyzer` that will help us analyze the random data. This class will have two methods: `analyze()` and `visualize()`.
```python
class DataAnalyzer:
    def __init__(self, data):
        self.data = data

    def analyze(self):
        # Calculate some basic statistics (mean, median, mode)
        mean = sum(self.data) / len(self.data)
        median = sorted(self.data)[len(self.data) // 2]
        mode = max(set(self.data), key=self.data.count)
        return {
            "mean": mean,
            "median": median,
            "mode": mode
        }

    def visualize(self):
        # Use matplotlib to create a simple bar chart
        import matplotlib.pyplot as plt

        plt.bar(range(len(self.data)), self.data)
        plt.xlabel("Index")
        plt.ylabel("Value")
        plt.title("Random Data Analysis")
        plt.show()
```
