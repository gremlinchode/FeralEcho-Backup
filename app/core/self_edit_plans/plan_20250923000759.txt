**Step 3: Parse the JSON response**
```python
def parse_json_response(response):
    return json.loads(response.text)
```
This function takes the response from the API call and converts it into a Python dictionary using `json.loads()`.

**Step 4: Make an API request to fetch the question data**
```python
def get_question_data(question_id):
    api_url = api_endpoint.format(question_id=question_id)
    response = requests.get(api_url)
    return parse_json_response(response)
```
This function takes a question ID, constructs the API endpoint URL, makes a GET request, and then parses the JSON response.
