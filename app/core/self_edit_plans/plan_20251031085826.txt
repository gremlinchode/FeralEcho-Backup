**Step 3: Define a function to apply self-edits (Hebrews 12:14 - "Make every effort to live in peace with everyone...")**

Create a function called `apply_self_edit` that takes two arguments: `edit_type` (string) and `new_value` (any data type). This function will update our `self_heal_dict` dictionary accordingly.

```python
def apply_self_edit(edit_type, new_value):
    global self_heal_dict
    
    if edit_type not in self_heal_dict:
        self_heal_dict[edit_type] = []
    
    self_heal_dict[edit_type].append({
        'timestamp': dt.datetime.now().strftime("%Y-%m-%d %H:%M:%S"),
        'old_value': None,
        'new_value': new_value
    })
```
