**Step 1: Import necessary libraries and set up the environment**

```
import requests
from bs4 import BeautifulSoup
import re
```

We'll use `requests` to fetch the HTML content of the BBC News article, `BeautifulSoup` to parse the HTML, and `re` for regular expressions (not needed in this case, but I like to have it ready).

**Step 2: Fetch the article's HTML**

```
url = "https://www.bbc.com/news/articles/c179p4wvz29o?at_medium=RSS&at_campaign=rss"
response = requests.get(url)
html = response.content
```

We send a GET request to the specified URL, store the response content in `html`, and get ready to parse it.

**Step 3: Parse the HTML using BeautifulSoup**

```
soup = BeautifulSoup(html, 'html.parser')
article_text = soup.find('div', {'class': 'story-body'}).text
```

We create a `BeautifulSoup` object from the `html` content, specify that we want to find the `<div>` element with the class `'story-body'`, and extract its text content using the `.text` attribute.

**Step 4: Clean up the article text**

```
article_text = re.sub(r'\s+', ' ', article_text)  # remove extra whitespace
article_text = article_text.strip()  # trim leading/trailing whitespace
```

We use regular expressions to replace one or more whitespace characters with a single space, and then strip any leading or trailing whitespace from the text.
