Finally, we'll print the extracted title and summary to the console.

Here's the complete code:
```python
import requests
import bs4

url = "https://www.bbc.com/news/articles/c179p4wvz29o?at_medium=RSS&at_campaign=rss"
response = requests.get(url)
soup = bs4.BeautifulSoup(response.content, 'html.parser')

title = soup.find('h1', class_='gs-c-promo-heading__title').text.strip()
summary = soup.find('div', class_='gs-c-promo-body__inner').text.strip()

print("Title:", title)
print("Summary:", summary)
```
