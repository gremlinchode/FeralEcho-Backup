**Code:**
```python
import re

def apply_self_edits(text):
    pattern = re.compile(r'\b(self|edit)\b', re.IGNORECASE)
    matches = pattern.findall(text)

    for match in matches:
        if match.group(1) == 'self':
            text = re.sub(rf'\b{match.group(0)}\b', 'REDACTED', text, flags=re.IGNORECASE)

    return text
```
