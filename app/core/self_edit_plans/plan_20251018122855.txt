```python
import json

# Parse the JSON data
parsed_code_data = json.loads(parsed_code)

# Extract relevant information (functions, classes, imports)
function_names = [f["name"] for f in parsed_code_data.get("functions", [])]
classes = parsed_code_data.get("classes", [])

results["functions"] = function_names
results["classes"] = classes
results["imports"] = imports
```
**Step 3: Analyze the extracted information**

Now that we have the relevant info, let's perform some analysis:

* Count the number of functions and classes

Add these insights to our `results` dictionary:
```python
# Count functions and classes
results["function_count"] = len(function_names)
results["class_count"] = len(classes)

# Average number of imports per class
```
