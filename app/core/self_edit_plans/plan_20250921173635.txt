**Step 1: Import necessary libraries**
```python
import requests
import json
from bs4 import BeautifulSoup
```
We'll use `requests` for API calls, `json` for parsing JSON data, and `BeautifulSoup` for HTML parsing.

**Step 2: Define the API endpoint and parameters**
```python
api_endpoint = "https://en.wikipedia.org/w/api.php"
params = {
    'action': 'query',
    'format': 'json',
    'prop': 'extracts',
    'titles': 'Artificial intelligence'
}
```
We'll use the MediaWiki API to retrieve the article's content. We set `action` to `query`, `format` to `json`, `prop` to `extracts`, and `titles` to the article title.

**Step 3: Send a GET request to the API**
```python
response = requests.get(api_endpoint, params=params)
```
We send a GET request to the MediaWiki API with the defined parameters.

**Step 4: Parse the JSON response**
```python
data = json.loads(response.text)
```
We parse the JSON response from the API using `json.loads`.

**Step 5: Extract the article content**
```python
article_content = data['query']['pages'][1164]['extract']
```
We extract the article content from the parsed JSON data. The page ID is `1164`, which corresponds to the "Artificial intelligence" article.

**Step 6: Clean up and preprocess the text data**
```python
import re
article_text = article_content.lower()
article_text = re.sub(r'\[.*?\]', '', article_text)
article_text = re.sub(r'\(.*?\)', '', article_text)
```
We convert the article content to lowercase, remove any brackets or parentheses using regular expressions, and store the cleaned text in `article_text`.

**Step 7: Perform natural language processing (NLP) tasks (optional)**
```python
import nltk
nltk.download('punkt')
```
