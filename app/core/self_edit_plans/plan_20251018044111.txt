Now, let's code:
```python
import requests
from bs4 import BeautifulSoup

article_url = "https://www.bbc.com/news/articles/c93dqew8l3xo?at_medium=RSS&at_campaign=rss"

response = requests.get(article_url)
soup = BeautifulSoup(response.content, 'html.parser')

title = soup.find('h1', class_='gs-c-promo-heading__title').text
print("Article Title:", title)

summary = soup.find('div', class_='gs-c-promo-summary').text
print("Summary:", summary)
```
**Step 5: Store the Results**
We'll create a dictionary to store the extracted data, and then print it out.
```python
data = {

print("Results:")

    print(f"{key}: {value}")
```
