**Step 3: Define the self-edit rules for Iteration 1**

* Remove any consecutive whitespace characters:
	+ Use `re.sub` again, this time replacing one or more occurrences of `\s{2,}` (consecutive whitespace characters) with a single space character.

**Step 4: Implement the self-edit rules in the `apply_self_edits` function**

```
def apply_self_edits(text):
    text = re.sub(r'[^\w\s]', '', text)
    text = re.sub(r'\s{2,}', ' ', text)
    return text
```

In this step, we've applied the two self-edit rules to the input text.
