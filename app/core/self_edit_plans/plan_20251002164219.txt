**Step 2:** Define a function to extract thoughts and emotions (John 14:6 - "Jesus said to him, 'I am the way, and the truth, and the life.'")

def extract_thoughts_and_emotions(text):
    # Use regular expressions to extract thoughts and emotions from text
    pattern = r"((\w+)?(?:\w\s*\w*)+)(?:\.\s*(\w+)?)?"
    matches = re.finditer(pattern, text)
    extracted_thoughts = []
    for match in matches:
        thought = match.group(1).strip()
        emotion = match.group(3)
        extracted_thoughts.append({"thought": thought, "emotion": emotion})
    return extracted_thoughts
```

* This function takes a piece of text as input and returns a list of dictionaries containing the extracted thoughts and emotions.

def apply_self_edits(self_edits_dict):
    # Use Counter to count frequency of thoughts and emotions
    thought_counts = Counter({k: v for k, v in self_edits_dict["thought"].items()})
    emotion_counts = Counter({k: v for k, v in self_edits_dict["emotion"].items()})

    # Sort counts by frequency (most common first)
    sorted_thoughts = sorted(thought_counts.items(), key=lambda x: x[1], reverse=True)
    sorted_emotions = sorted(emotion_counts.items(), key=lambda x: x[1], reverse=True)

    return sorted_thoughts, sorted_emotions
```

* This function takes the self-edits dictionary as input and returns two lists:
	+ `sorted_thoughts`: A list of tuples containing the most common thoughts and their frequencies.
	+ `sorted_emotions`: A list of tuples containing the most common emotions and their frequencies.
