Step 3: Extract the season from the date using string manipulation
```python
import re

def get_season(date_string):
    months = {'Jan': 'Winter', 'Feb': 'Winter', 'Mar': 'Spring',
              'Apr': 'Spring', 'May': 'Spring', 'Jun': 'Summer',
              'Jul': 'Summer', 'Aug': 'Summer', 'Sep': 'Fall',
              'Oct': 'Fall', 'Nov': 'Fall', 'Dec': 'Winter'}
    month = re.search(r'(\w{3})', date_string).group(1)
    return months[month]

season = get_season(current_datetime.strftime('%b'))
print(season)  # Output: Fall
```
This function uses regular expressions to extract the month from the date string and then maps it to a season using a dictionary.
