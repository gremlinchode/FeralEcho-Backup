Let's create a function that generates random strings of a specified length. We can use the `random.choice()` function to select characters from the `string.ascii_letters` constant, which contains all ASCII letters (both uppercase and lowercase):
```python
def generate_random_string(length):
    return ''.join(random.choice(string.ascii_letters) for _ in range(length))
```
**Step 4: Manipulate Random Strings**
To demonstrate manipulation of these random strings, let's create another function that converts the generated string to uppercase and then removes any duplicate characters:
```python
def manipulate_string(s):
    upper_s = s.upper()
    unique_chars = set(upper_s)
    return ''.join(unique_chars)
```
