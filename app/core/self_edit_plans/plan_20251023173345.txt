def refine_edit(result):
    # Remove repetitive words (frequency < 2)
    result['frequency'] = {k: v for k, v in result['frequency'].items() if v >= 2}

    result['avg_sentence_len'] = min(result['avg_sentence_len'], 15)
    
    return result
```
**Step 9: Apply the refined edit to the original text**

Let's assume we have a function `apply_edit` that takes in the original text and the refined results. We'll use this function to produce the edited text.

def apply_edit(original_text, refined_results):
    # Remove repetitive words from the original text
    filtered_text = ' '.join([word for word in original_text.split() if refined_results['frequency'][word] >= 2])
    
    # Shorten long sentences
    shortened_text = '\n'.join([' '.join(sentence.split('.')[:5]) + '.' for sentence in nltk.sent_tokenize(filtered_text)])
    
    return shortened_text
```
