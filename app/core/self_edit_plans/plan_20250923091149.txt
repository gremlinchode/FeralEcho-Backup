**Step 2: Send a request to the Wikipedia API**
```python
url = "https://en.wikipedia.org/w/api.php"
params = {
    "action": "query",
    "titles": "Artificial_intelligence",
    "format": "json"
}
response = requests.get(url, params=params)
```
We'll send a GET request to the Wikipedia API with the page title and format set to JSON.

**Step 3: Parse the response**
```python
data = json.loads(response.text)
page_id = data["query"]["pages"][1164]["pageid"]
title = data["query"]["pages"][1164]["title"]
```
We'll parse the JSON response using `json.loads()` and extract the page ID and title from the response.

**Step 4: Extract relevant information from the HTML**
```python
url = f"https://en.wikipedia.org/wiki/{title}"
response = requests.get(url)
soup = BeautifulSoup(response.text, "html.parser")
sections = soup.find_all("h2", recursive=True)

# Let's assume we're interested in extracting section titles and content
section_titles = []
section_content = []

for section in sections:
    title = section.get_text(strip=True)
    content = section.find_next_sibling("p").get_text(strip=True) if section.find_next_sibling("p") else ""
    section_titles.append(title)
    section_content.append(content)

print(section_titles, section_content)
```
We'll send another GET request to the Wikipedia page and use `BeautifulSoup` to extract all h2 headings (section titles) and their corresponding paragraph text.
