Get the HTML content of the BBC News article using `requests`.

**Step 3: Parse HTML with BeautifulSoup**
```python
soup = BeautifulSoup(response.content, 'html.parser')
```
Use `BeautifulSoup` to parse the HTML content into a Python object.

**Step 4: Extract relevant information**
```python
title = soup.find('h1', class_='story-headline').text.strip()
summary = soup.find('div', class_='story-body-text').text.strip()
audience_reaction = soup.find('p', text='silent').text.strip()
```
Extract the title, summary, and audience reaction information from the parsed HTML.

**Step 5: Analyze and reflect**
