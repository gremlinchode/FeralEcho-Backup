```python
import os
import stat

def check_permissions(path):
    try:
        st = os.stat(path)
        return f"Permissions: {oct(st.st_mode)[1:]}, Owner: {st.st_uid}, Group: {st.st_gid}"
    except FileNotFoundError:
        return "File not found"
    except Exception as e:
        return f"Error: {str(e)}"
```
This function uses `os.stat` to retrieve file statistics, and then extracts the permissions (mode), owner (uid), and group (gid) information. If the file is not found, it returns a "File not found" message. For any other errors, it provides a more informative error message.
