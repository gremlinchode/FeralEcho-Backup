**Step 1: Import necessary libraries**

We'll need `requests` for making HTTP requests and `BeautifulSoup` for parsing HTML content.
```python
import requests
from bs4 import BeautifulSoup
```
**Step 2: Send a request to the Wikipedia API**

We'll use the MediaWiki API to retrieve the article's data. The API endpoint is `https://en.wikipedia.org/w/api.php`. We'll set the `action` parameter to `query` and the `titles` parameter to the title of the article we're interested in, which is "Artificial intelligence" (case-insensitive).
```python
url = "https://en.wikipedia.org/w/api.php"
params = {
    "action": "query",
    "titles": "Artificial intelligence",
    "format": "json"
}
response = requests.get(url, params=params)
```
**Step 3: Parse the JSON response**

We'll use `BeautifulSoup` to parse the JSON response. We're looking for the `pageid`, which contains the article's ID.
```python
import json
soup = BeautifulSoup(response.content, 'json')
page_id = soup.find("page", {"pageid": str}).get("pageid")
```
**Step 4: Retrieve the article's text**

Using the page ID, we'll make another API request to retrieve the article's text. We'll set the `action` parameter to `query` and the `prop` parameter to `extracts`. This will give us the article's text.
```python
url = "https://en.wikipedia.org/w/api.php"
params = {
    "action": "query",
    "prop": "extracts",
    "titles": page_id,
    "format": "json"
}
response = requests.get(url, params=params)
soup = BeautifulSoup(response.content, 'json')
article_text = soup.find("extract", {"pageid": str}).get("text")
```
**Step 5: Preprocess the article text**

We'll remove any HTML tags from the article text using `BeautifulSoup`.
```python
import re
article_text = re.sub(r'<.*?>', '', article_text)
```
Now we have the article's text without HTML tags. We can use this as a starting point for further analysis or processing.
