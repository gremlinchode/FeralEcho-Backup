Here's the complete code:
```python
import wikipedia
import json

page_info = wikipedia.page('Artificial intelligence')

title = page_info.title
display_title = page_info.displaytitle
namespace_id = page_info.namespace.id
wikibase_item = page_info.wikibase_item
page_id = page_info.pageid
lang = page_info.lang
dir = page_info.dir
revision = page_info.revision
timestamp = page_info.timestamptaken

page_json = {
    'title': title,
    'display_title': display_title,
    'namespace_id': namespace_id,
    'wikibase_item': wikibase_item,
    'page_id': page_id,
    'lang': lang,
    'dir': dir,
    'revision': revision,
    'timestamp': timestamp
}

print(json.dumps(page_json, indent=4))
```
Now, if you run this code, it should output a JSON object containing the relevant information about the "Artificial intelligence" Wikipedia page.
