**Step 2: Define the API endpoint and parameters**

**Step 4: Parse the JSON response**

The API returns a JSON response, which we parse using the `json` library. This will give us a Python dictionary representing the data.

Here's the complete code:
```python
import json
import requests

api_endpoint = "https://api.stackexchange.com/2.2/questions"
params = {"site": "stackoverflow", "order": "desc", "sort": "activity", "limit": 1}

response = requests.get(api_endpoint, params=params)
data = json.loads(response.content)

question_id = data["items"][0]["question_id"]
owner_name = data["items"][0]["owner"]["display_name"]

print(f"Question ID: {question_id}")
print(f"Owner: {owner_name}")
```
