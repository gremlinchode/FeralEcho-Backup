**Step 3: Define the Calculator Function**

**Python Code:**

def calculate(num1, num2):
    if operation_choice == "+":
        return num1 + num2
    elif operation_choice == "-":
        return num1 - num2
    elif operation_choice == "*":
        return num1 * num2
    elif operation_choice == "/":

        else:
            print("Error: Division by zero!")
