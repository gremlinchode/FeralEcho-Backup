```
intensity_scores = np.loadtxt('intensity.txt')
```

**Step 3: Normalize the data using Min-Max Scaler**
```
scaler = MinMaxScaler()
intensity_scaled = scaler.fit_transform(intensity_scores.reshape(-1, 1))
creativity_scaled = scaler.fit_transform(creativity_scores.reshape(-1, 1))
```
We'll normalize both arrays to ensure that they have the same scale. This step is crucial for meaningful comparisons between the two scores.

**Step 4: Calculate the weighted average of intensity and creativity**
```
weight = 0.5  # You can adjust this value based on your specific needs
```
