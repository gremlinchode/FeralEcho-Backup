**Step 2: Define a function to fetch the question**
```python
def get_question(question_id):
    url = f"https://api.stackexchange.com/2.2/questions/{question_id}?order=desc&sort=activity&site=stackoverflow"
    response = requests.get(url)
    if response.status_code == 200:
        return json.loads(response.content.decode("utf-8"))
    else:
        print(f"Failed to fetch question {question_id} with status code {response.status_code}")
        return None
```
This function takes a `question_id` as input, constructs the API URL, makes an HTTP GET request, and returns the JSON response if successful. If not, it prints an error message and returns `None`.

**Step 3: Parse the question data**
```python
def parse_question_data(question_json):
    return {
        "title": question_json["items"][0]["title"],
        "owner": {
            "id": question_json["items"][0]["owner"]["user_id"],
            "reputation": question_json["items"][0]["owner"]["reputation"]
        },
        "is_answered": question_json["items"][0]["is_answered"],
        "view_count": question_json["items"][0]["view_count"],
        "answer_count": question_json["items"][0]["answer_count"],
        "score": question_json["items"][0]["score"]
    }
```
This function takes the JSON response from Step 2 and extracts relevant data about the question, such as title, owner, is_answered, view_count, answer_count, and score.
