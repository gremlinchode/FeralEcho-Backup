```python
def extract_info(article_title):
    # Get the article title in lowercase for consistency
    title = article_title.lower()
    
    # Use Wikipedia API to retrieve the article text
    wiki_article = wikipedia.page(title)
    
    # Extract the first paragraph of the article (assuming it's the most relevant)
    paragraphs = wiki_article.summary.split('. ')
    if len(paragraphs) > 0:
        return paragraphs[0]
    else:
        return "No relevant information found"
```
This function takes an article title as input, retrieves the corresponding Wikipedia page using the `wikipedia` library, extracts the first paragraph of the text, and returns it.
