2. **Define a function for self-edits**: This function will take in a user-inputted text, apply random edits (iteration 1), and return the edited text.
```python
def self_edit(text):
    # Implement iteration 1: random word substitution
    words = text.split()
    for i, word in enumerate(words):
        if random.randint(0, 1):  # 50% chance of replacement
            words[i] = random.choice(string.ascii_lowercase + " ")
    return ' '.join(words)
```
3. **Test the function**: Let's test our `self_edit` function with a sample text.
