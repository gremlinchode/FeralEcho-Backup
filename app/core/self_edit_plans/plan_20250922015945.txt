**Step 4: Extract Components**
Now, we'll iterate through the AST tree to extract the functions, classes, and imports:
```python
components = []

def get_components(node):
    if isinstance(node, ast.FunctionDef):
        components.append({"name": node.name, "args": node.args})
    elif isinstance(node, ast.ClassDef):
        components.append({"name": node.name, "bases": node.bases})
    elif isinstance(node, ast.Import):
        components.append({"name": node.names[0].name})

get_components(tree)
```
In this code snippet:

* We define a recursive function `get_components()` to traverse the AST tree.
* We check the type of each node using `isinstance()`. If it's a function definition (`FunctionDef`), class definition (`ClassDef`), or import statement (`Import`), we extract the relevant information and add it to our `components` list.

**Step 5: Print Results**
Finally, print the extracted components:
```python
print(components)
```
This will output a list of dictionaries containing the functions, classes, and imports found in the parsed code.
