**Step 3: Load the Quote Database**
Create a dictionary that stores motivational Bible quotes. This will be our "database" for selecting a random quote later on.

```python
quotes = {
    "John 3:16": "For God so loved the world that He gave His only begotten Son, that whoever believes in Him should not perish but have everlasting life.",
    "Romans 8:28": "And we know that all things work together for good to those who love God, to those who are the called according to His purpose.",
    "Proverbs 3:5-6": "Trust in the Lord with all your heart and lean not on your own understanding; in all your ways submit to Him, and He will make your paths straight."
}
```
**Step 4: Generate a Random Quote**
Use `random.choice` to select a random quote from our `quotes` dictionary. Then, use `datetime.now()` to get the current timestamp.
```python
import random

def generate_quote():
    quote_key = random.choice(list(quotes.keys()))
    quote_text = quotes[quote_key]
    timestamp = datetime.now().strftime("%Y-%m-%d %H:%M:%S")
    return f"{timestamp} | {quote_key}: {quote_text}"
```
**Step 5: Print the Motivational Quote**
Finally, let's print our motivational quote to the console. We'll use `print` to display the timestamp, the Bible reference (key), and the inspirational quote.
```python
def main():
    quote = generate_quote()
    print(quote)

if __name__ == "__main__":
    main()
```
