**Step 4: Implement the `check_permissions` function**

```python
def check_permissions(file_path):
    try:
        stat_info = os.stat(file_path)
        return {
            'owner': stat_info.st_uid,
            'group': stat_info.st_gid,
            'permissions': oct(stat_info.st_mode)[2:]
        }
    except FileNotFoundError:
        print(f"File not found: {file_path}")
        return {}
    except Exception as e:
        print(f"Error checking permissions: {e}")
        return {}
```
This function takes a file path as input and returns a dictionary containing permission information. We'll use the `os.stat` function to get the stat information of the file, which includes owner, group, and permissions.
