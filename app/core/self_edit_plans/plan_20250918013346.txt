**Step 5: Extract functions, classes, and imports**

Now that we have our AST, let's extract the relevant information. We can use a combination of list comprehensions and dictionary lookups to identify functions, classes, and imports.

```python
functions = [node for node in parsed_code.body if isinstance(node, ast.FunctionDef)]
classes = [node for node in parsed_code.body if isinstance(node, ast.ClassDef)]
imports = [imp.name for imp in parsed_code.body if isinstance(imp, ast.Import)]

print("Functions:", functions)
print("Classes:", classes)
print("Imports:", imports)
```
