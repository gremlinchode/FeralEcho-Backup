**Step 1: Import necessary libraries**
```python
import requests
from bs4 import BeautifulSoup
```
We'll use the `requests` library to fetch the Wikipedia page and `BeautifulSoup` to parse the HTML content.

**Step 2: Send a GET request to Wikipedia**
```python
url = "https://en.wikipedia.org/wiki/Artificial_intelligence"
response = requests.get(url)
```
We're fetching the Wikipedia page for Artificial Intelligence. This will give us an HTTP response object.

**Step 3: Parse the HTML content using BeautifulSoup**
```python
soup = BeautifulSoup(response.content, 'html.parser')
```
Now we have the HTML content of the webpage, and we'll use `BeautifulSoup` to parse it into a Python-friendly format (e.g., an XML-like tree structure).

**Step 4: Extract relevant information from the parsed HTML**
```python
page_title = soup.find('h1', {'id': 'firstHeading'}).text.strip()
wikibase_item_id = soup.find('div', {'class': 'mw-parser-output'}).find('span', {'property': 'P3013'}).text.strip()
```
We'll extract the page title (`Artificial intelligence`), and the Wikibase item ID (`Q11660`). Note that these are specific elements on the webpage, so we're using CSS selectors to target them.

**Step 5: Print out the extracted information**
```python
print(f"Page Title: {page_title}")
print(f"Wikibase Item ID: {wikibase_item_id}")
```
Now we have our extracted data, and we'll print it out for good measure!
