**Step 3: Implement basic text manipulation**

```python
def remove_stopwords(text):
    stopwords = ["the", "and", "a", "an", "in", "to"]
    cleaned_text = re.sub(r"\b(" + "|".join(stopwords) + r")\b", "", text, flags=re.IGNORECASE)
    return cleaned_text

def split_sentences(text):
    sentences = re.split(r"[.!?]", text)
    return sentences
```
We'll create two utility functions: `remove_stopwords()` to remove common stop words from the input text and `split_sentences()` to break the text into individual sentences.

**Step 4: Implement sentence-level editing**
```python
def edit_sentence(sentence):
    # For now, just capitalize the first letter of each sentence
    return sentence.capitalize()

def self_edit(self):
    edited_text = ""
    for sentence in split_sentences(self.text):
        edited_sentence = edit_sentence(sentence)
        edited_text += edited_sentence + " "
    return edited_text.strip()
```
Our `self_edit()` method will iterate through the sentences, apply basic editing (capitalizing the first letter), and concatenate the results.
