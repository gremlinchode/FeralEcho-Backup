**Step 2: Define a function to fetch the question details**

```python
def get_question_details(question_id):
    url = f"https://api.stackexchange.com/2.2/questions/{question_id}/?site=stackoverflow&key=YOUR_API_KEY"
    response = requests.get(url)
    data = json.loads(response.text)
    return data['items'][0]
```
In this function, we'll use the Stack Exchange API to fetch the question details given the `question_id`. We'll need to replace `YOUR_API_KEY` with your actual API key. The function returns a dictionary containing the question details.

**Step 3: Extract specific fields from the question data**
```python
def extract_fields(question_data):
    owner_data = question_data['owner']
    tags = [tag['name'] for tag in question_data['tags']]
    view_count = question_data['view_count']
    answer_count = question_data['answer_count']
    score = question_data['score']
    
    return {
        'owner': {'id': owner_data['user_id'], 'reputation': owner_data['reputation']},
        'tags': tags,
        'view_count': view_count,
        'answer_count': answer_count,
        'score': score
    }
```
This function takes the question data and extracts specific fields of interest, such as the owner's reputation, tags, view count, answer count, and score.
