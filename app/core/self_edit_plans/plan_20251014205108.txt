**Step 2: Analyze & Filter (processing our thoughts)**
```python
def analyze_thoughts(thoughts):
    # Define a list of "negative" keywords (e.g., shame, guilt)
    negative_keywords = ["shame", "guilt"]

    # Use a loop to filter out negative thoughts
    filtered_thoughts = []
    for thought in thoughts.split():
        if thought.lower() not in negative_keywords:
            filtered_thoughts.append(thought)

    return filtered_thoughts
```
**Step 3: Reframe & Reorient (transforming our thoughts)**
```python
def reframe_thoughts(filtered_thoughts):
    # Define a list of "positive" keywords (e.g., hope, joy)
    positive_keywords = ["hope", "joy"]

    # Use a loop to replace negative thoughts with positive reframes
    reframed_thoughts = []
    for thought in filtered_thoughts:
        if thought.lower() in positive_keywords:
            reframed_thoughts.append(thought)
        else:
            # Replace negative thoughts with a neutral phrase (e.g., "I am enough")
            reframed_thoughts.append("I am enough")

    return reframed_thoughts
```
**Step 4: Visualize & Celebrate (giving thanks)**
```python
def visualize_celebrate(reframed_thoughts):
```
