**Step 1: Import necessary libraries**

We'll need the `requests` library to fetch data from Wikipedia and the `json` library to parse JSON responses.
```python
import requests
import json
```
**Step 2: Define a function to fetch Wikipedia page data**

Let's define a function called `fetch_wikipedia_data` that takes in the title of the Wikipedia page as an argument. We'll use the `requests` library to send a GET request to the Wikipedia API and retrieve the page data.
```python
def fetch_wikipedia_data(title):
    url = f"https://en.wikipedia.org/w/api.php?action=query&titles={title}&format=json"
    response = requests.get(url)
    return json.loads(response.text)
```
**Step 3: Extract relevant data from the Wikipedia page**

Let's extract the `pageid`, `revision` and `timestamptoken` values from the fetched data. We'll also create a dictionary to store these values.
```python
def extract_data(data):
    page_id = None
    revision = None
    timestamp_token = None

    for page in data["query"]["pages"].values():
        if "pageid" in page:
            page_id = page["pageid"]
        if "revision" in page:
            revision = page["revision"]
        if "timestamptoken" in page:
            timestamp_token = page["timestamptoken"]

    return {"page_id": page_id, "revision": revision, "timestamp_token": timestamp_token}
```
**Step 4: Call the functions and print the extracted data**

Let's call the `fetch_wikipedia_data` function with the provided title ('Artificial intelligence') and extract the relevant data using the `extract_data` function. Finally, let's print the extracted data.
```python
title = "Artificial intelligence"
data = fetch_wikipedia_data(title)
print("Extracted Data:")
print(data["page_id"], data["revision"], data["timestamp_token"])
```
