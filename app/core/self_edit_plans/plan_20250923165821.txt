**Step 4: Implement logic within `parse_line` to extract functions, classes, and imports**
```python
def parse_line(line):
    # Split the line into individual tokens (e.g., words)
    tokens = line.split()

    # Check if the line contains a function declaration
    if any(token.startswith('def ') for token in tokens):
        # Extract function name and parameters
        func_name = next((token for token in tokens if token.startswith('def ')), None)
        func_params = []
        for token in tokens[tokens.index(func_name) + 1:]:
            if token.startswith('(') or token.startswith('['):
                break
            elif token.endswith(')') or token.endswith(']'):
                break
            else:
                func_params.append(token)

        # Store function info in the results dictionary
        results['functions'].append({'name': func_name, 'params': func_params})

    # Check if the line contains a class declaration
    elif any(token.startswith('class ') for token in tokens):
        # Extract class name and base class (if present)
        cls_name = next((token for token in tokens if token.startswith('class ')), None)
        cls_base = None
        for token in tokens[tokens.index(cls_name) + 1:]:
            if token.startswith('(') or token.startswith('['):
                break
            elif token.endswith(')') or token.endswith(']'):
                break
            else:
                if token == 'class':
                    cls_base = token
                elif token == '(':
                    break

        # Store class info in the results dictionary
        results['classes'].append({'name': cls_name, 'base': cls_base})

    # Check if the line contains an import statement
    elif any(token.startswith('import ') for token in tokens):
        # Extract import module name(s)
        imports = [token for token in tokens if token.startswith('import ')]

        # Store import info in the results dictionary
        results['imports'].extend(imports)

    return results
```
This step implements the logic within our `parse_line` function. We split each line into individual tokens, then check if the line contains a function declaration (e.g., `def my_func()`), a class declaration (e.g., `class MyClass:`), or an import statement (e.g., `import module`). For each type of declaration, we extract relevant information and store it in the `results` dictionary.

**Step 5: Return the parsed results**

```python
return results
```
