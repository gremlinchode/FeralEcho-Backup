Here's the complete code:
```python
import wikipedia
from datetime import datetime
import json

page = wikipedia.page('Artificial intelligence')

wikidata_item_id = page.wikibase_item
page_title = page.title
revision_timestamp = datetime.fromtimestamp(page.revision)

data_points = {
    'wikidata_item_id': wikidata_item_id,
    'page_title': page_title,
    'revision_timestamp': revision_timestamp.isoformat()
}

data_json = json.dumps(data_points)
print(data_json)
```
