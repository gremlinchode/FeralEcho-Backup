```python
def check_permissions(file_path):
    try:
        # Use os.stat() to get file stats
        file_stats = os.stat(file_path)
        return f"Permissions: {oct(file_stats.st_mode)}"
    except FileNotFoundError:
        return "File not found"
```
This function uses `os.stat()` to retrieve the file's statistics, which includes its permission mode. We'll convert this mode into an octal string for easy reading.
