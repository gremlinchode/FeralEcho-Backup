```
def clarity_diagnosis(words):
    for word in words:
        if word.startswith('what', 'why', 'how') or word in ['explain', 'define']:
            return "Confusing"
        elif any(word == 'the' or word == 'and' for word in ['a', 'an']):
            return "Wordy"
        else:
            return "Clear"

clarity_result = clarity_diagnosis(input_analysis(text))

```

**Step 3: Tone Detection**
```
def tone_detection(words):
    tone_map = {
        'positive': ['good', 'great', 'excellent'],
        'negative': ['bad', 'terrible', 'awful'],
        'neutral': ['just', 'fair', 'okay']
    }
    for word in words:
        if word in tone_map['positive']:
            return "Positive"
        elif word in tone_map['negative']:
            return "Negative"
        else:
            return "Neutral"

tone_result = tone_detection(input_analysis(text))
print(f"Tone: {tone_result}")
```
This step identifies the overall tone of your writing. Is it uplifting, critical, or neutral? This information will help me refine your text to achieve the desired tone.

**Step 4: Usefulness Assessment**
```
def usefulness_assessment(words):
    for word in words:
        if word.startswith('how', 'what') or word == 'benefit':
            return "Helpful"

            return "Problematic"
        else:
            return "Neutral"

usefulness_result = usefulness_assessment(input_analysis(text))
print(f"Usefulness: {usefulness_result}")
```
This step evaluates the text's usefulness by identifying key phrases related to problem-solving, benefits, or answers. If your writing is helpful in these areas, it will receive a positive assessment.
