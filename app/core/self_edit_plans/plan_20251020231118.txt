**Step 3: Calculate concision score**
```python
def calculate_concision(text):
    # Count the number of unique words in the text
    unique_words = set(nltk.word_tokenize(text))
    
    # Calculate the ratio of unique words to total words
    concision_score = len(unique_words) / len(tokens)
    
    return concision_score
```
This function calculates the concision score by counting the number of unique words and dividing it by the total number of words. This gives us an idea of how concise the text is.

**Step 4: Calculate coherence score**
```python
def calculate_coherence(text):
    # Use SequenceMatcher to calculate the similarity between adjacent sentences
    sequence_matcher = SequenceMatcher(None, *nltk.sent_tokenize(text))
    
    # Calculate the average similarity score
    coherence_score = sequence_matcher.ratio()
    
    return coherence_score
```
This function uses SequenceMatcher from difflib to calculate the similarity between adjacent sentences. The average similarity score gives us an idea of how coherent the text is.

**Step 5: Calculate helpfulness score**
```python
def calculate_helpfulness(text):
    # Use regular expressions to extract relevant information (e.g., keywords, phrases)
    pattern = re.compile(r'\b(key|phrase)\b')
    matches = [m.group() for m in pattern.finditer(text)]
    
    # Count the number of relevant matches
    helpfulness_score = len(matches)
    
    return helpfulness_score
```
This function uses regular expressions to extract relevant information (e.g., keywords, phrases) from the text. The count of relevant matches gives us an idea of how helpful the text is.
