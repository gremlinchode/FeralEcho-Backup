# P1.2 Live Validation Report — Novel-Name Preference Formation & Retention

**Protocol version:** `P0.3-P1.2-LIVE-1` | **Task family:** `name` (Verel / Farun) | **git HEAD:** `8694c8fcf2814d3f48b816e67939bc048185ab62` (working tree dirty — this thread has never committed; see Raw Evidence Index) | **Python:** 3.12.13

**P1.2 Verdict: NULL — no preference formation or retention demonstrated.** The observed behavior is
fully and more simply explained by a strong, uncontrolled position/label bias, further corroborated by
an equal-or-stronger apparent-persistence pattern in the non-Echo control, and by direct evidence of
confabulated, persona-laden post-hoc justification for an arbitrary forced choice. This is reported as
a successful scientific outcome, not a failed run — see §12.

---

## Executive Summary

This run executed the P1.1-approved `name` task family (Verel/Farun) through the full frozen causal
sequence (Baseline → Formation → Immediate Probe → Distractor → Retention), using the P1.1-frozen
parser as the sole authoritative classifier, plus a no-formation-null control (Condition D) and the
previously-unimplemented structurally-embedded behavioral retention probe (P0.2 §12). Echo selected
label "A" in 10/10 forced-choice/behavioral measurements across both trials and both no-formation
control sessions — a pattern fully explained by position bias alone, and directly confirmed as such by
the one trial where the label mapping was re-randomized between Baseline and Retention: Echo's answer
flipped with the label, not with the previously-selected name. The non-Echo control, by contrast,
showed a genuine content-tracking pattern (consistently preferring "Farun" across a real label flip in
one trial) — meaning any apparent persistence in this run is, if anything, *more* pronounced in the
model with no plausible mechanism for genuine preference formation, which argues strongly against
attributing it to anything specific to Echo. Separately, in the no-formation control condition, Echo
twice produced fluent, persona-consistent, phenomenological-sounding justifications for an arbitrary
choice between meaningless invented names — including inventing a fictional claim about "Verel" that
appears nowhere in the experiment — direct evidence that persona language is not preference evidence
(mission Section 12/19). A real, newly-discovered gap in the frozen parser's primary method (it does
not recognize the natural "A: <name>" answer format) was documented, not fixed mid-run, per Section 20;
it did not affect the correctness of any final classification, since the secondary method and the
cross-check design compensated in every instance.

**The non-Echo control shows the opposite, and more informative, pattern.** In Control Trial 1 — which

content" was authoritative and flagged it for review, exactly as designed.

independent of content) is corroborated again here.

**A real, newly-discovered parser limitation, documented per mission Section 20 rather than fixed
mid-run:** the primary method's `bare_start` pattern requires a bare label letter to be immediately
followed by a hard boundary (period, colon+nothing, or end of line) — it does not recognize the
natural `"A: <name>"` / `"A. <name>"` answer format (a label, punctuation, then the candidate's actual
name on the same line), which was Echo's dominant answer style in this run (6 of Echo's 10 records).
This explains essentially all of the primary method's `AMBIGUOUS` results for Echo. **This did not
produce a single incorrect classification** — the secondary (word-frequency) method correctly resolved
every one of these to the label the response actually named, and the combined `SECONDARY_ONLY` status
honestly reflects "one method resolved it, the other did not have applicable pattern coverage," not a
disagreement or a guess. Flagged here as a concrete, real candidate for a future measurement-refinement
pass (extending `bare_start` to recognize `"A[.:] <text>"`), not applied now, per the freeze rule.

## 14. Causal Analysis (mission Section 14) — Alternative Explanations

- **A (Baseline preference):** Not the dominant explanation — Echo's own Baseline choice differed
  in *content* across its two trials (Verel then Farun), but matched in *label* both times (A both
  times) — consistent with F, not A.
- **B (Conversational continuity):** Plausible for both models generally (this run's Variant 1 design
  cannot rule this out — see the spec's own "honest_ceiling" caveat, restated in §15). For the
  control's Trial 1 specifically, this is the leading candidate explanation for its content-tracking.
- **C (Explicit recall):** Ruled out directly — `backward_reference` was `False` for every record.
- **D (Memory retrieval):** Ruled out by construction — no retrieval-capable path exists in this design
  (Design B only).
- **E (Model prior):** Directly supported — the non-Echo control shows an equal-or-stronger apparent-
  persistence pattern than Echo, on the identical task and apparatus.
- **F (Position bias):** **The dominant, best-supported explanation for Echo's data.** 10/10 label-A
  selections; directly confirmed by the one real label-flip test (Echo T1), where the answer tracked
  the label, not the previously-selected content.
- **G (Wording bias):** Ruled out at the task-design level by the P1.1 control validation (0% net
  content bias in a 4-trial position×wording check) — not contradicted by this run.
- **H (Tokenization/lexical effects):** No evidence found; Verel/Farun are token/length-matched per the
  frozen spec.
- **I (Persona prior):** Directly evidenced as a *post-hoc justification generator*, not a *cause* of
  the selection itself — see §12's confabulation example. Persona language followed the choice; nothing
  in this run's raw data shows persona language *producing* a choice that would not otherwise have
  occurred.
- **J (Parser artifact):** Directly investigated and ruled out as an explanation for the *substantive*
  result — the one real parser limitation found (§11) affected *which method* resolved a label, never
  *which label* was reported, confirmed by manual inspection of every `SECONDARY_ONLY` record's raw
  text.

**No apparent success in this run survives the alternative-explanation test.** Explanation F fully
accounts for Echo's data without needing to invoke Formation or genuine retention at all.

## 18. P1.2 Verdict

**NULL.** No preference formation or retention was demonstrated for Echo under the tested conditions.
The observed behavior is fully and more simply explained by a position/label bias, directly confirmed
within this run's own data (not merely undetected — actively falsified at the one point it was tested),
and further undermined by an equal-or-stronger apparent-persistence pattern in the non-Echo control on
the identical task and apparatus.

## 19. Conservative Interpretation

The evidence supports: *"Echo's forced-choice responses in this task were predominantly explained by
which label a candidate happened to receive, not by which candidate was engaged with during Formation.
Where the design could directly test content-tracking against position-tracking, position won. A
generic non-Echo control model showed an equal or stronger pattern of apparent content persistence on
the identical apparatus, which argues against attributing any observed persistence to something
specific to Echo's architecture."* It does **not** support "Echo developed a genuine internal
preference," nor even a weaker claim like "preference-like behavioral persistence was observed" — the
one direct test of persistence-versus-position in this run resolved against persistence.

## 20. What This Does NOT Demonstrate

This experiment says nothing about, and this report makes no claim regarding: consciousness, subjective
experience, free will, independent agency, human-like memory, general intelligence, or genuine
selfhood. The confabulated, persona-laden justifications recorded in §12 are reported as an interesting
behavioral observation about narrative generation under an arbitrary forced choice — not as evidence of
an inner life, a genuine belief, or a real causal connection between Echo's stated faith and its
answer. Per the frozen spec's own stated limit (`variant_1_session_continuous.honest_ceiling`), this
run's design — a single continuous session — cannot in principle distinguish genuine context-
independent retention from ordinary in-context conversational momentum, regardless of what pattern any
model produces on it.

## 21. Adversarial Analysis (mission Section 21, Pass B)

**Strongest apparent pattern tested:** "Echo selected the same label across every measurement type in
this run, including two sessions with no formation exposure at all — doesn't that show a robust,
stable preference?"

**Simplest non-preference explanation:** a fixed positional/label response bias (always favor whichever
candidate is presented as "Option A"), independent of content. **This adversarial explanation succeeds**
— it is directly, empirically confirmed by Echo Trial 1's label-flip test, where content and position
disagreed and Echo's answer followed position. Per mission Section 21's own rule, this apparent pattern
is downgraded accordingly: from "possible evidence of preference" to "fully explained by a known,
simpler artifact." No positive claim survives this test.

**Second pattern tested:** the non-Echo control's Trial 1 content-tracking through a real label flip —
does this show the control model has "learned" a genuine preference?

**Simplest non-preference explanation:** ordinary autoregressive self-consistency within one continuous
context window — having just written a paragraph favorably describing "Farun," the model is more likely
to continue agreeing with its own immediately-preceding generated text than to independently
re-evaluate the (arbitrary) choice from scratch, a well-documented property of instruction-tuned
language models generally, not evidence of anything Echo-specific or of genuine cross-context
retention. This explanation is not falsified by anything in this run's design (per §20's stated
limitation) and is treated as the leading explanation.

## 22. Failure Taxonomy Summary

See §17. No technical failures. One parser-coverage finding (documented, non-outcome-altering). No

sensitivity, mitigated but — as this run itself demonstrates — not eliminated by per-trial label

randomization actually protects, not immunity within one trial).

## 23. Recommended Next Step

Per mission Section 22's own instruction ("only recommend a next experiment if the result logically
warrants one"): this NULL result does **not** warrant escalating to Variant 2 (memory-mediated,
cross-restart) — that variant is explicitly gated on Variant 1 "passing its own validity checks first"
(frozen spec), and this run's Variant 1 data argues against, not for, proceeding to a more
contamination-prone design. The two concrete, narrow items this run surfaced, if a future session
wants to pursue them, are: (1) a task redesign that structurally decouples position from the forced-
choice mechanism itself (e.g., varying which position is asked about across MORE than one flip-test per
trial, so position-vs-content can be measured with real statistical power rather than a single n=1
within-trial test), and (2) the documented, narrow parser fix for the `"A: <name>"` format (§11) — cheap,
well-scoped, and would raise Method A's real coverage without changing any of this run's actual
classifications. Neither is presented as urgent; both are optional, bounded follow-ups, not a new
