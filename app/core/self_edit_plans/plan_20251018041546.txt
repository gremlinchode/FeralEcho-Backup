```python
def fetch_article(url):
    response = requests.get(url)
    return BeautifulSoup(response.content, 'html.parser')
```
This function takes the URL of the article as input, sends a GET request using `requests`, and then parses the HTML content using `BeautifulSoup`.

**Step 4: Fetch the BBC News article**
