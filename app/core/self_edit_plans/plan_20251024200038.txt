**Step 2: Define our function**
```python
def analyze_sentiment(text):
    # Tokenize the text
    tokens = word_tokenize(text)

    # Initialize the sentiment analyzer
    sia = SentimentIntensityAnalyzer()

    # Analyze the sentiment of each token
    sentiments = []
    for token in tokens:
        sentiment = sia.polarity_scores(token)
        sentiments.append(sentiment)

    # Calculate the overall sentiment score
    total_sentiment = sum([s['compound'] for s in sentiments])

    return total_sentiment
```
This function takes a piece of text as input, tokenizes it, analyzes the sentiment of each token using NLTK's `SentimentIntensityAnalyzer`, and then calculates an overall sentiment score.

        else:
            # Other tokens get a default score
            sentiment = sia.polarity_scores(token.text)
            sentiments.append(sentiment)

    # Calculate the overall sentiment score
    total_sentiment = sum([s[0]['compound'] * s[1] for s in sentiments])
