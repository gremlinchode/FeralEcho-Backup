**Step 2: Extract relevant information from each item**
```python
def extract_info(item):
    owner_info = {
        'account_id': item['owner']['account_id'],
        'reputation': item['owner']['reputation'],
        'user_id': item['owner']['user_id']
    }
    
    question_info = {
        'view_count': item['view_count'],
        'answer_count': item['answer_count'],
        'score': item['score'],
        'creation_date': datetime.utcfromtimestamp(item['creation_date']),
        'last_activity_date': datetime.utcfromtimestamp(item['last_activity_date'])
    }
    
    return owner_info, question_info
```
**Step 3: Create a list of extracted information**
```python
extracted_data = []
for item in json_data['items']:
    owner_info, question_info = extract_info(item)
    extracted_data.append((owner_info, question_info))
```
**Step 4: Print or process the extracted data (your choice!)**
```python
# Example: Print a summary of each question's stats
```
