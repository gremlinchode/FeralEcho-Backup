**Step 1: Import necessary libraries**
```python
import requests
from bs4 import BeautifulSoup
import json
```
We'll use the `requests` library to fetch the Wikipedia page, `BeautifulSoup` to parse the HTML, and `json` to handle the extracted data.

**Step 2: Fetch the Wikipedia page**
```python
url = "https://en.wikipedia.org/wiki/Artificial_intelligence"
response = requests.get(url)
page_html = response.content
```
We'll send a GET request to the URL and store the HTML content in the `page_html` variable.

**Step 3: Parse the HTML using BeautifulSoup**
```python
soup = BeautifulSoup(page_html, 'html.parser')
```
We'll create a BeautifulSoup object from the HTML content, specifying the parser as `'html.parser'`.

**Step 4: Find the relevant section (Artificial Intelligence) and extract its contents**
```python
section_title = "Artificial_intelligence"
section_tag = soup.find('h2', text=section_title)
if section_tag:
    section_contents = section_tag.find_next_sibling('div')
    if section_contents:
        # Extract text from the section
        section_text = ''
        for para in section_contents.find_all('p'):
            section_text += para.text + '\n'
```
We'll find the `<h2>` tag with the desired title and extract its contents. Then, we'll iterate through the paragraphs (`<p>`) within that section and concatenate their text content.

**Step 5: Convert the extracted text to JSON**
```python
import json
section_json = {'text': section_text}
json_string = json.dumps(section_json)
```
We'll convert the extracted text into a JSON object and store it as a string using `json.dumps()`.

**Step 6: Print or use the extracted data (optional)**
```python
print(json_string)

```
