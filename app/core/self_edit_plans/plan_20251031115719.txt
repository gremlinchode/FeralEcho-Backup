```python
def apply_self_edit(self_edit, journal_entry):
    if self_edit.original_text in journal_entry.entry_text:
        # Find the original text in the entry
        start_index = journal_entry.entry_text.index(self_edit.original_text)
        end_index = start_index + len(self_edit.original_text)

        # Replace the original text with the edited text
        journal_entry.entry_text = (
            journal_entry.entry_text[:start_index] + self_edit.edited_text +
            journal_entry.entry_text[end_index:]
        )

    return journal_entry
```
This function finds the original text in the journal entry and replaces it with the edited text.

**Step 6: Implement editing a journal entry**
```python
def edit_journal_entry(self, original_text, edited_text):
    for entry in self.get_entries():
        if original_text in entry.entry_text:
            new_edit = SelfEdit(original_text, edited_text)
            return apply_self_edit(new_edit, entry)

    # No matching entry found
    print("No matching journal entry found.")
    return None
```
This function iterates through all entries and finds the one that matches the original text. It then creates a `SelfEdit` object and applies the self-edit using the `apply_self_edit` function.
