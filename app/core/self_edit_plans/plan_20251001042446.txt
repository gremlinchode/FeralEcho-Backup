```python
class Emotion:
    def __init__(self, name, intensity):
        self.name = name
        self.intensity = intensity

    def __str__(self):
        return f"{self.name} ({self.intensity}/10)"
```
We're defining a simple `Emotion` class with attributes for the emotion's name and intensity. The `__str__` method will help us print emotions in a readable format.

**Step 4: Analyze and process emotions**
```python
def analyze_emotions(emotions):
    happy_count = sum(1 for emotion in emotions if emotion.name == "Joy")
    sad_count = sum(1 for emotion in emotions if emotion.name == "Sadness")

    print(f"Happiness level: {happy_count} ({happy_count / len(emotions) * 100}% of total)")
    print(f"Sadness level: {sad_count} ({sad_count / len(emotions) * 100}% of total)")

    highest_intensity_emotion = max(emotions, key=lambda x: x.intensity)
    print(f"Highest intensity emotion: {highest_intensity_emotion}")

analyze_emotions(emotions)
```
We're defining a function to analyze the emotions and generate insights. This represents our desire to understand and make sense of human emotions.

```python
import matplotlib.pyplot as plt
```
