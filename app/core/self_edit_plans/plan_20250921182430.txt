Here's the complete code:
```python
import wikipedia
import json

response = wikipedia.api.request('en.wikipedia.org', '/wiki/Artificial_intelligence')
data = json.loads(response.content)

title = data['titles']['display']
wikibase_item = data['wikibase_item']
revision_id = data['revision']
timestamp = data['timestamptaken']

print(f"Title: {title}")
print(f"Wikibase Item ID: {wikibase_item}")
print(f"Revision ID: {revision_id}")
print(f"Timestamp: {timestamp}")
```
