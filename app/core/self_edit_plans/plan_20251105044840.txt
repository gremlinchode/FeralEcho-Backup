Now that we have some basic building blocks, let's combine them to create something more interesting. We can define a function that uses the Person class and interacts with the user:

```python
def chatbot():
    person = Person(input("Enter your name: "))
    while True:
        greeting = random.choice(["Hello", "Hi", "Hey"])
        print(f"{greeting}, {person.name}!")
        response = input("What would you like to talk about? ")
        if response.lower() == "goodbye":
            goodbye(person.name)
            break
```
This chatbot function uses the Person class and interacts with the user through a simple conversation.
