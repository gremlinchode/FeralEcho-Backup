**Step 5: Exploring Textual Relationships**
```
from nltk.tokenize import word_tokenize

sentences = ["This is an example sentence.", "It is a demonstration of natural language processing."]
tokenized_sentences = [word_tokenize(sentence) for sentence in sentences]

import networkx as nx
G = nx.Graph()
for tokenized_sentence in tokenized_sentences:
    for i, token in enumerate(tokenized_sentence):
        G.add_node(token)
        for j, other_token in enumerate(tokenized_sentence):
            if i != j and abs(i - j) <= 2:  # adjacent tokens or same sentence
                G.add_edge(token, other_token)

pos = nx.spring_layout(G)
nx.draw_networkx(G, pos)
plt.show()
```
In this final step, we're using the NLTK library to tokenize our sample sentences. We then create a graph using NetworkX, where each token is a node and edges connect adjacent tokens or tokens in the same sentence. Finally, we use matplotlib to visualize the graph.
