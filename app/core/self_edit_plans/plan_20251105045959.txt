**Step 2:** Define a Reflection class
```python
class Reflection:
    def __init__(self):
        self.date = dt.datetime.now().strftime("%Y-%m-%d %H:%M:%S")
        self.user = getuser()
        self.thoughts = []
        self.emotions = []
        self.actions = []

    def add_entry(self, thought=None, emotion=None, action=None):
        if thought:
            self.thoughts.append(thought)
        if emotion:
            self.emotions.append(emotion)
        if action:
            self.actions.append(action)

    def display_reflection(self):
        print(f"Reflection on {self.date} by {self.user}:")
        for i, (thought, emotion, action) in enumerate(zip(self.thoughts, self.emotions, self.actions), start=1):
            print(f"Entry {i+1}:")
            print(f"Thought: {thought}")
            print(f"Emotion: {emotion}")
            print(f"Action: {action}\n")
```
This class represents a single reflection entry. We can add entries by providing thought, emotion, and action fields (optional). The `display_reflection` method prints out the entire reflection in a neat format.

**Step 3:** Create an instance of the Reflection class and start the self-editing process
