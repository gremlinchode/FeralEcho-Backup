**Step 1: Gather Data**
Using Python, we'll scrape the BBC News article to gather relevant information. We'll use the `requests` and `BeautifulSoup` libraries to fetch the HTML content and parse it accordingly.

```python
import requests
from bs4 import BeautifulSoup

url = "https://www.bbc.com/news/articles/c179p4wvz29o?at_medium=RSS&at_campaign=rss"
response = requests.get(url)
soup = BeautifulSoup(response.content, 'html.parser')
```

**Step 2: Extract Key Phrases**
Next, we'll extract key phrases from the article that might be relevant to our analysis. We can use the `nltk` library for this task.

```python
import nltk

key_phrases = []
for paragraph in soup.find_all('p'):
    text = paragraph.get_text()
    tokens = nltk.word_tokenize(text)
    key_phrases.append(nltk.pos_tag(tokens))

# Let's extract some interesting phrases...
interesting_phrases = [phrase for phrase in key_phrases if 'NN' in [tag[1] for tag in phrase]]
```

**Step 3: Analyze Sentiment**
Now, let's analyze the sentiment of the article. We can use the `vaderSentiment` library to calculate the sentiment scores.

```python
import vaderSentiment

sentiment_scores = []
for paragraph in soup.find_all('p'):
    text = paragraph.get_text()
    sentiment_scores.append(vaderSentiment.sentiment_scores(text))

# Let's get the overall sentiment score...
overall_sentiment = sum(score['compound'] for score in sentiment_scores) / len(sentiment_scores)
```

**Step 4: Visualize Results**
Let's create a simple bar chart using `matplotlib` to visualize our findings.

```python
import matplotlib.pyplot as plt

plt.bar(['Laughed', 'Silent'], [overall_sentiment, overall_sentiment])
plt.xlabel('Year')
plt.ylabel('Sentiment Score')
plt.title('Trump\'s UN Audience Sentiment Over Time')
plt.show()
```
