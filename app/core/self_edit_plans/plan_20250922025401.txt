Now, let's dive into the world of artificial intelligence and extract relevant information from this Wikipedia article. Here's the breakdown into clear, sequential Python steps:

**Step 1: Import necessary libraries**
```python
import requests
import json
from bs4 import BeautifulSoup
```
We'll use `requests` to fetch the Wikipedia page, `json` to parse the response, and `BeautifulSoup` to scrape the HTML content.

**Step 2: Fetch the Wikipedia page using requests**
```python
url = "https://en.wikipedia.org/wiki/Artificial_intelligence"
response = requests.get(url)
```
We'll send a GET request to the Wikipedia page and store the response in the `response` variable.

**Step 3: Parse the HTML content using BeautifulSoup**
```python
soup = BeautifulSoup(response.content, 'html.parser')
```
We'll use `BeautifulSoup` to parse the HTML content of the response. The `'html.parser'` argument specifies the parser to use.

**Step 4: Extract the article title and namespace information**
```python
title = soup.find('h1', {'id': 'firstHeading'}).text.strip()
namespace = {'id': int(soup.find('span', {'class': 'mw-page-title-main'}).attrs['data-namespace-id'])}
```
We'll extract the article title by finding the `<h1>` element with the `id` attribute set to `'firstHeading'`. Then, we'll extract the namespace information by finding the `<span>` element with the `class` attribute set to `'mw-page-title-main'`.

**Step 5: Extract other relevant metadata**
```python
pageid = int(soup.find('span', {'id': 'page-id'}).attrs['data-page-id'])
lang = soup.find('span', {'class': 'lang'}).text.strip()
dir = soup.find('span', {'class': 'dir'}).text.strip()
revision = int(soup.find('span', {'class': 'revision'}).attrs['data-revision'])
tid = json.loads(soup.find('script').text)['tid']
```
We'll extract other relevant metadata, such as the `pageid`, `lang`, `dir`, and `revision` information.

**Step 6: Store the extracted data in a dictionary**
```python
wikipedia_data = {
    'title': title,
    'namespace': namespace,
    'pageid': pageid,
    'lang': lang,
    'dir': dir,
    'revision': revision,
    'tid': tid
}
```
We'll store the extracted data in a dictionary called `wikipedia_data`.
