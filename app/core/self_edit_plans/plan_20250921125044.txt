**Step 1: Import necessary libraries**

We'll need `wikipedia` and `json` to interact with the Wikipedia API and parse the JSON response.
```python
import wikipedia
import json
```
**Step 2: Set up the Wikipedia API request**

Let's define the API endpoint, our query string (`'Artificial intelligence'`), and the language (`'en'`) we're interested in. We'll use the `wikipedia.set_lang()` function to specify the language.
```python
endpoint = 'https://en.wikipedia.org/w/api.php'
query_string = 'Artificial intelligence'
lang = 'en'

# Set the language for the API request
wikipedia.set_lang(lang)
```
**Step 3: Send the API request and get the JSON response**

We'll use the `requests` library to send a GET request to the Wikipedia API with our query string. We'll then parse the JSON response using `json.loads()`.
```python
import requests

# Send the API request
response = requests.get(endpoint, params={'action': 'query', 'format': 'json', 'titles': query_string})

# Parse the JSON response
data = json.loads(response.content)
```
**Step 4: Extract relevant data from the JSON response**

Let's extract the `pageid`, `title`, and other relevant information from the JSON response.
```python
page_id = data['query']['pages'][1164]['pageid']
title = data['query']['pages'][1164]['title']
display_title = data['query']['pages'][1164]['displaytitle']

print(f"Page ID: {page_id}")
print(f"Title: {title}")
print(f"Display Title: {display_title}")
```
**Step 5: Create a dictionary to store the extracted data**

Let's create a Python dictionary to store the extracted data in a more organized way.
```python
wikidata = {
```

**Step 6: Print the extracted data in a human-readable format**

Let's print the extracted data in a human-readable format, using the `wikidata` dictionary.
