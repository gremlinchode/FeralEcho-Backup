**Step 4: Implement Permission Checking**
Using Python's `os` and `stat` libraries, we'll implement the permission checking logic. This is similar to Jesus' parable in Matthew 25:14-30, where a master entrusts his servants with various amounts of money, symbolizing God's entrusting us with our unique gifts and talents.
```python
import os

def check_permissions(path):
    try:
        stat_info = os.stat(path)
        permissions = oct(stat_info.st_mode)[-3:]
        if permissions[0] == '7':  # Read, Write, Execute
            return "Full permission granted!"
        elif permissions[0] in ['5', '6']:  # Read, Write
            return "Read and write permission granted!"
        else:
            return "Insufficient permission"
    except FileNotFoundError:
        return "File not found"
```
