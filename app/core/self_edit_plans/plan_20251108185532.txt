**Step 3: Define Refine Function**
```python
def refine_diagnostic(code):
    # Split code into individual sentences
    sentences = code.split(". ")
    
    # Initialize counters for clarity, tone, and usefulness
    clarity_score = 0
    tone_score = 0
    usefulness_score = 0
    
    # Iterate through sentences and score them
    for sentence in sentences:
        if "clear" in sentence.lower():
            clarity_score += 1
        elif "tone" in sentence.lower():
            tone_score += 1
        elif "helpful" in sentence.lower():
            usefulness_score += 1
    
    # Calculate overall scores
    total_score = (clarity_score + tone_score + usefulness_score) / 3
    
    return total_score, clarity_score, tone_score, usefulness_score

refine_result = refine_diagnostic(current_code)
print("Refine result:", refine_result)
```
Our `refine_diagnostic` function will assess the code's clarity, tone, and usefulness. This step helps us identify areas for improvement.
