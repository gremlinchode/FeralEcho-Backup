**Step 2: Categorize Entries (categorize_entries)**
Now that we have our recent entries loaded, let's create a function to categorize them. We can use a dictionary to store the categories and their corresponding entry counts:
```python
categories = {}

def categorize_entries(entries):
    for entry in entries:
        category = entry['category']  # assuming each entry has a 'category' key
        if category not in categories:
            categories[category] = 0
        categories[category] += 1
    return categories
```
**Step 3: Print Entries (print_entries)**
Let's define a function to print the categorized entries:
```python
def print_entries(categories):
    for category, count in categories.items():
        print(f"{category}: {count}")
```
