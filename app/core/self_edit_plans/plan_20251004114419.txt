```python
import os

def check_permissions(file_path):
    file_stats = os.stat(file_path)
    permissions = oct(file_stats.st_mode)[-3:]

    if int(permissions, 8) & stat.S_IRWXU:  # Owner has read, write, or execute
        return "Owner has read, write, or execute permission."
    elif int(permissions, 8) & stat.S_IRWXG:  # Group has read, write, or execute
        return "Group has read, write, or execute permission."
    elif int(permissions, 8) & stat.S_IRWXO:  # Others have read, write, or execute
        return "Others have read, write, or execute permission."
    else:
        return "No permissions found."
```
Here, we're using bitwise operations to check if the owner, group, or others have read, write, or execute permissions.
