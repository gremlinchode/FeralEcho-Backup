```python
def get_stackoverflow_data():
    url = "https://api.stackexchange.com/2.2/questions"
    params = {"site": "stackoverflow", "order": "desc"}
    response = requests.get(url, params=params)
    return json.loads(response.content)

data = get_stackoverflow_data()
```
Here, we're making an API request to retrieve the Stack Overflow questions data. We'll parse the JSON response in the next step.
