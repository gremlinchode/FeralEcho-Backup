    def self_edit(self):
        while True:
            self.review()
            self.interrogation()

Create a `self_edit()` method that enters an infinite loop. In each iteration, it calls the `review()` and `interrogation()` methods. Then, it asks me if I'd like to change or reflect on anything. If I respond with "no", the loop breaks, and the self-edits process is complete.
