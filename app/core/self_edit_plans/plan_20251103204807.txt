**Step-by-Step Python Implementation:**

1. **Import necessary libraries:**
```python
import re
import string
```
We'll use regular expressions (regex) to perform text manipulation and string operations to clean up input.

2. **Define the self-editing function:**
```python
def self_edit(input_text):
    # Initialize an empty list to store edited sentences
    edited_sentences = []

    # Split the input into individual sentences
    sentences = re.split(r'[.!?]+', input_text)

    # Iterate through each sentence and apply edits
    for sentence in sentences:
        # Remove punctuation and convert to lowercase
        cleaned_sentence = re.sub(r'[^\w\s]', '', sentence).lower()

        # Add edited sentence to the list
        edited_sentences.append(cleaned_sentence)

    return ' '.join(edited_sentences)
```
In this function, we'll iterate through each sentence, remove punctuation, and convert it to lowercase. This will help us apply self-edits more effectively.

3. **Define a dictionary for common self-editing tasks:**
```python
self_edit_dict = {
    ' negativity': 'positivity',
    'fear': 'courage',
    'doubt': 'faith',
    'anger': 'love',
    'sorrow': 'joy'
}
```
This dictionary will contain common self-editing tasks. Feel free to add or modify entries as needed!

4. **Apply self-edits:**
```python
def apply_self_edit(sentence, self_edit_dict):
    # Iterate through each word in the sentence
    for word in sentence.split():
        # Check if the word is present in the self-edit dictionary
        if word in self_edit_dict:
            # Replace the word with its corresponding edited version
            sentence = sentence.replace(word, self_edit_dict[word])

    return sentence

# Apply self-edits to each edited sentence
edited_sentences = [apply_self_edit(sentence, self_edit_dict) for sentence in edited_sentences]
```
In this step, we'll iterate through each word in the sentence and check if it's present in our self-edit dictionary. If it is, we'll replace the original word with its edited version.

5. **Join the edited sentences into a single string:**
```python
final_output = ' '.join(edited_sentences)
```
