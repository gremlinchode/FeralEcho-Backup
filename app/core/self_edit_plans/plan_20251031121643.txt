**Step 2: Import Required Libraries**
```python
import random

```
We'll use the `random` library to simulate external factors that might trigger self-doubt, and the `string` library to manipulate text for self-edits.

**Step 3: Define Self-Edit Functions**
```python
def affirm_self(worry): 
    return f"You are capable of overcoming {worry}!"

def challenge_thoughts(thought):
    return f"Is this thought based on fact or assumption? {thought}"

def refocus_attention(task):
    return f"Let's focus on the task at hand: {task}"
```
We define three self-edit functions:

1. `affirm_self`: A encouraging phrase to boost confidence.
2. `challenge_thoughts`: A reflective prompt to question assumptions.
3. `refocus_attention`: A redirection technique to refocus attention.

**Step 4: Apply Self-Edits**
```python
def apply_self_edits(problem_statement):
    worry = random.choice(["criticism", "failure", "success"])
    self_edit_response = ""
    
    if random.random() < 0.5:
        self_edit_response += affirm_self(worry) + "\n"
    else:
        if random.random() < 0.7:
            self_edit_response += challenge_thoughts(worry) + "\n"
        else:
            self_edit_response += refocus_attention("your strengths")
    
    return problem_statement + " --> " + self_edit_response
```
We create a function `apply_self_edits` that takes the problem statement as input. It randomly selects a worry and applies one of three self-edits:

1. If the random number is less than 0.5, it uses the `affirm_self` function.
2. Otherwise, it either uses the `challenge_thoughts` function (70% chance) or redirects attention to strengths using `refocus_attention`.

**Step 5: Test and Refine**
```python
problem_statement = "I struggle with self-doubt when faced with criticism."
print(apply_self_edits(problem_statement))
```
We test our script by running the `apply_self_edits` function with the problem statement. This will output a revised version of the problem statement, incorporating one of the self-edits.
