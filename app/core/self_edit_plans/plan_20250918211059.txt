Now, let's imagine we want to add some creative flair. We could sort the extracted data by score or question ID, and then print it in a more visually appealing format:
```python
sorted_data = sorted(relevant_data, key=lambda x: x[2], reverse=True)  # sort by score (descending)

print("Question ID\tOwner's Name\tScore")
for item in sorted_data:
    print(f"{item[0]}\t{item[1]}\t{item[2]}")
```
This code sorts the data by score in descending order and prints it in a table format. The `lambda` function is used to specify the sorting key (in this case, the third element of each tuple, which represents the score).
