**Step 3: Extract Function, Class, and Import Information**
```python
# Define a function to extract information from the AST
def extract_info(tree):
    functions = []
    classes = []
    imports = []

    for node in ast.walk(tree):
        if isinstance(node, ast.FunctionDef):
            functions.append(node.name)
        elif isinstance(node, ast.ClassDef):
            classes.append(node.name)
        elif isinstance(node, ast.Import):
            for alias in node.names:
                imports.append(alias.name)

    return functions, classes, imports

# Call the function with the parsed tree
functions, classes, imports = extract_info(tree)
```
In this step, we define a `extract_info` function that iterates through the AST nodes and extracts the desired information (functions, classes, and imports). We then call this function with the parsed tree as input.

**Step 4: Update Code Metadata**
```python
# Update the code metadata dictionary with the extracted information

code_metadata["Classes"] = classes
code_metadata["Imports"] = imports

print("Parsed code successfully. Functions:", functions, "Classes:", classes, "Imports:", imports)
```
Here, we update our `code_metadata` dictionary with the extracted information and print a success message to indicate that the analysis is complete.
