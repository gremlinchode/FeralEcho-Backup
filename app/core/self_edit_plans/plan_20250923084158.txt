**Step 1: Import necessary libraries**
```python
import requests
import json
from bs4 import BeautifulSoup
```
We'll use `requests` to fetch the Wikipedia page, `json` to parse the response, and `BeautifulSoup` to scrape the HTML content.

**Step 2: Define the Wikipedia API endpoint**
```python
wikipedia_api_endpoint = "https://en.wikipedia.org/w/api.php"
```
We'll use this endpoint to query the Wikipedia AI page.

**Step 3: Set up the API request**
```python
params = {
    'action': 'query',
    'format': 'json',
    'titles': 'Artificial intelligence'
}
```
In this step, we're constructing a JSON object to send as our API request. We're specifying the `action` as `query`, the `format` as `json`, and the `title` as `Artificial intelligence`.

**Step 4: Send the API request**
```python
response = requests.get(wikipedia_api_endpoint, params=params)
```
Now we send a GET request to the Wikipedia API endpoint with our constructed JSON object.

**Step 5: Parse the response**
```python
data = json.loads(response.text)
```
We use `json.loads()` to convert the response text into a Python dictionary.

**Step 6: Extract relevant information from the parsed data**
```python
page_title = data['query']['pages']['1164']['title']
page_id = data['query']['pages']['1164']['id']
revision_timestamp = data['query']['pages']['1164']['revisions'][0]['timestamp']
```
In this step, we're extracting specific information from the parsed data, such as the page title, ID, and revision timestamp.

**Step 7: Use Beautiful Soup to scrape HTML content**
```python
soup = BeautifulSoup(response.text, 'html.parser')
```
Now we use Beautiful Soup to parse the HTML response text into a Python object. This will allow us to extract specific elements from the page.

**Step 8: Extract relevant information from the scraped HTML**
```python
page_summary = soup.find('div', {'class': 'mw-page-summary'}).text.strip()
```
In this step, we're using Beautiful Soup to find specific elements on the page (in this case, the summary) and extract their text content.

And that's it! We've broken down the task of extracting information from a Wikipedia AI page into Python steps.
