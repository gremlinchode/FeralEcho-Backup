**Step 1: Import the necessary modules**
```python
import sys
import os
```
We need `sys` for system-related operations and `os` for working with the operating system.

**Step 2: Check if 'key' is a valid attribute**
```python
try:
    key = getattr(sys, 'key')
except AttributeError as e:
    print(f"Error: {e}. The 'key' attribute does not exist.")
```
We use `getattr` to attempt to retrieve the value of `'key'`. If it raises an `AttributeError`, we catch it and print a message indicating that the attribute doesn't exist.

**Step 3: Gather environment information**
```python
if key is None:
    try:
        key = os.environ['KEY']
    except KeyError as e:
        print(f"Error: {e}. Environment variable 'KEY' not set.")
```
If `key` is still `None`, we try to retrieve the value from the operating system's environment variables using `os.environ`. If the `KEY` environment variable is not set, we catch the `KeyError` and print a message indicating that it's not set.

**Step 4: Print the gathered information**
```python
if key is not None:
    print(f"Environment info: {key}")
```
If we successfully retrieved the value of `key`, we print it to the console. Otherwise, we just print a success message.

Here's the complete code:
```python
import sys
import os

try:
    key = getattr(sys, 'key')
except AttributeError as e:
    print(f"Error: {e}. The 'key' attribute does not exist.")

if key is None:
    try:
        key = os.environ['KEY']
    except KeyError as e:
        print(f"Error: {e}. Environment variable 'KEY' not set.")

if key is not None:
    print(f"Environment info: {key}")
```
