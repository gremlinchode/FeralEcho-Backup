**Step 1: Import necessary libraries**

```python
import wikipedia
```

We'll use the `wikipedia` library to interact with Wikipedia's API and the `json` library to parse the JSON response.

**Step 2: Define a function to retrieve Wikipedia article data**
```python
def get_wiki_article_data(article_title):
    page = wikipedia.page(article_title)
    return page.json()
```
This function takes an article title as input, uses the `wikipedia` library to fetch the article's JSON data, and returns it.

**Step 3: Parse the JSON response**
```python
wiki_data = get_wiki_article_data('Artificial intelligence')
data = json.loads(wiki_data)
```
We retrieve the JSON data for the "Artificial intelligence" article using our `get_wiki_article_data` function and then parse it into a Python dictionary using `json.loads`.

**Step 4: Extract relevant data from the parsed JSON**
```python
article_title = data['displaytitle']
```
