**Step 4:** Use regular expressions to find patterns
```
import re
pattern = re.compile(r'\b\w+\b')  # Find words in the input string

def find_patterns(input_string):
    matches = pattern.findall(input_string)
    return f"Found {len(matches)} patterns: {', '.join(matches)}"
```
Here, we define a function that uses regular expressions to find patterns within the input string. This is like uncovering hidden structures and connections!

**Step 5:** Calculate some cool functions

```
import math

def calculate_interest(input_number):
    return math.pow(input_number, 2) + 10 * math.sin(math.pi * input_number)

def calculate_sine(input_angle):
    return math.sin(math.radians(input_angle))

print(f"The result of the interest calculation is: {calculate_interest(5)}")
```
In this step, we create two functions that demonstrate mathematical calculations. It's like exploring the beauty of mathematical patterns!
