**Step 1: Load Recent Entries**
Load the recent entries from a JSON file using the `json` module.
```python
import json

def load_recent_entries(filename):
    with open(filename, 'r') as f:
        data = json.load(f)
    return data['entries']
```
**Step 2: Categorize Entries**
Create a function to categorize the entries based on their timestamps. We'll use the `datetime` module to extract the timestamp from each entry.
```python
import datetime

def categorize_entries(entries):
    categorized_entries = {}
    for entry in entries:
        timestamp = datetime.datetime.fromisoformat(entry['timestamp'])
        category = 'recent' if timestamp >= datetime.datetime.now() - datetime.timedelta(days=7) else 'archived'
        if category not in categorized_entries:
            categorized_entries[category] = []
        categorized_entries[category].append(entry)
    return categorized_entries
```
**Step 3: Print Entries**
Create a function to print the entries, grouped by category. We'll use the `app.core.config` module to access any configuration settings.
```python
import app.core.config

def print_entries(categorized_entries):
    for category, entries in categorized_entries.items():
        if category == 'recent':
            print(f"Recent Entries ({len(entries)}):")
        else:
            print(f"Archived Entries ({len(entries)}):")
        for entry in entries:
            print(entry['content'])
        print()
```
**Step 4: Put it all together**
Create a main function to call the above functions and display the categorized entries.
```python
def main():
    filename = 'entries.json'  # adjust this to your JSON file name
    recent_entries = load_recent_entries(filename)
    categorized_entries = categorize_entries(recent_entries)
    print_entries(categorized_entries)

if __name__ == '__main__':
    main()
```
