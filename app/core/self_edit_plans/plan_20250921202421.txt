We'll use `requests` to fetch the Wikipedia page data, `json` to parse JSON responses, and `BeautifulSoup` (BS4) for HTML parsing.

**Step 2: Define a function to scrape Wikipedia data**
```python
def get_wikipedia_data(title):
    url = f"https://en.wikipedia.org/w/api.php?action=query&titles={title}&prop=extracts&format=json"
    response = requests.get(url)
    data = json.loads(response.content)
    return data['query']['pages'].get('146')  # Assuming the pageid is 146
```
This function takes a Wikipedia title as input, constructs the API URL, sends an HTTP request, parses the JSON response, and returns the page data.

**Step 3: Call the function with the task's Wikipedia title**
```python
data = get_wikipedia_data('Artificial intelligence')
```
We pass the title 'Artificial intelligence' to our `get_wikipedia_data` function.

**Step 4: Extract relevant data from the response**
```python
page_data = data['extract']

```
We extract the page's summary text using BS4 and print it.
