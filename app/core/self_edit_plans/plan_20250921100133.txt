**Step 3: Extract relevant information from the page's HTML content**
```python
soup = BeautifulSoup(page.html(), 'html.parser')
```
Parse the HTML content of the page using `BeautifulSoup`. This will allow us to extract specific elements and data from the page.

**Step 4: Identify relevant sections (e.g., Summary, Types, History)**
```python
sections = []
for tag in soup.find_all(['h2', 'h3']):
    section_title = tag.text.strip()
    if section_title:
        sections.append(section_title)
```
Find all `h2` and `h3` tags on the page, extract their text content (section titles), and store them in a list.

**Step 5: Extract relevant information from each section**
```python
relevant_info = {}
for section_title in sections:
    for paragraph in soup.find_all('p'):
        if section_title in paragraph.text:
            relevant_info[section_title] = [paragraph.text.strip()]
```
