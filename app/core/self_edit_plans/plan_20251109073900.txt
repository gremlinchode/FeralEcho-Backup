**Step 3: Parse the code using regular expressions**
```python
import re

def parse_code(code):
    pattern = r'function\s+([a-zA-Z_][a-zA-Z0-9_]*)\s*\(.*\)'
    matches = re.finditer(pattern, code)
    functions = [match.group(1) for match in matches]
    return functions
```
