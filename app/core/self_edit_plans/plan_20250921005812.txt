**Step 1: Import required libraries**
```python
import requests
import json
from bs4 import BeautifulSoup
```
We'll use `requests` for HTTP requests, `json` for parsing JSON responses, and `BeautifulSoup` for parsing HTML.

**Step 2: Send a GET request to the Wikipedia API**
```python
url = "https://en.wikipedia.org/w/api.php"
params = {
    "action": "query",
    "format": "json",
    "titles": "Artificial intelligence",
    "prop": "extracts"
}
response = requests.get(url, params=params)
```
We'll send a GET request to the Wikipedia API with the required parameters: `action=query`, `format=json`, and `titles=Artificial intelligence`. This will fetch the page's extract (summary) in JSON format.

**Step 3: Parse the JSON response using BeautifulSoup**
```python
data = json.loads(response.text)
page_data = data["query"]["pages"][1164]["extract"]
soup = BeautifulSoup(page_data, "html.parser")
```
We'll parse the JSON response into a Python dictionary using `json.loads()`. Then, we'll extract the page's content (the summary) and convert it to an HTML string using `BeautifulSoup`.

**Step 4: Extract relevant information from the HTML**
```python
title = soup.find("span", {"class": "mw-page-title-main"}).text
description = soup.find("div", {"class": "pi-item pi-item-title"}).text
```
We'll use BeautifulSoup to find and extract the page title (`Artificial intelligence`) and description (the summary) from the HTML.

**Step 5: Print the extracted information**
```python

```
Finally, we'll print out the extracted title and description to the console.

Here's the complete code:
```python
import requests
import json
from bs4 import BeautifulSoup

url = "https://en.wikipedia.org/w/api.php"
params = {
    "action": "query",
    "format": "json",
    "titles": "Artificial intelligence",
    "prop": "extracts"
}
response = requests.get(url, params=params)

data = json.loads(response.text)
page_data = data["query"]["pages"][1164]["extract"]
soup = BeautifulSoup(page_data, "html.parser")

title = soup.find("span", {"class": "mw-page-title-main"}).text
description = soup.find("div", {"class": "pi-item pi-item-title"}).text

print(f"Title: {title}")
print(f"Description: {description}")
```
