**Step 1: Parse the date and time**
We need to extract the relevant information from the current date and time string.

```python
import datetime

current_datetime = "2025-10-13T13:54:32.344648-07:00"
date_time_obj = datetime.datetime.strptime(current_datetime, "%Y-%m-%dT%H:%M:%S.%f%z")

# Extract the year, month, day, hour, minute, and second
year = date_time_obj.year
month = date_time_obj.month
day = date_time_obj.day
hour = date_time_obj.hour
minute = date_time_obj.minute
second = date_time_obj.second

print(f"Year: {year}, Month: {month}, Day: {day}, Hour: {hour}, Minute: {minute}, Second: {second}")
```
