**Step 2: Define constants**
```python

# Set a threshold value (e.g., 0.5) for determining the edit type
```

**Step 3: Normalize input values**
```python

print("Normalized intensity:", intensity_normalized)
print("Normalized creativity:", creativity_normalized)
```
We'll normalize the input values to ensure they fall within a standardized range.

**Step 4: Determine edit type based on threshold**
```python
if intensity_normalized < THRESHOLD and creativity_normalized > THRESHOLD:
    edit_type = "Minor"
elif intensity_normalized > THRESHOLD and creativity_normalized < THRESHOLD:
    edit_type = "Major"
else:
    edit_type = "None"

print("Edit type:", edit_type)
```
We'll use the normalized values to determine the type of self-edit. If the intensity is below the threshold and creativity is above, it's a minor edit. If the intensity is above and creativity is below, it's a major edit. Otherwise, there's no edit.
