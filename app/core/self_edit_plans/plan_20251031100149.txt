**Step-by-Step Instructions:**

1. **Import necessary libraries:**
```python
import re
from string import punctuation
```
We'll use regular expressions (re) and the string module's punctuation constant for text manipulation.

2. **Define the self-editing functions:**
```python
def remove_punctuation(text):
    return ''.join(ch for ch in text if ch not in punctuation)

def lowercase_text(text):
    return text.lower()

def replace_words(text, old_word, new_word):
    return re.sub(old_word, new_word, text)
```
These functions will help us apply the self-edits. We'll remove punctuation, convert the text to lowercase, and replace specific words.

3. **Read in the input text:**
```python
input_text = input("Enter your text for initial self-edits: ")
```
The user will provide the text they'd like to edit.

4. **Apply the self-edits:**

a. Remove punctuation:
```python
cleaned_text = remove_punctuation(input_text)
```

b. Convert to lowercase:
```python
lowercase_text = lowercase_text(cleaned_text)
```

c. Replace specific words (e.g., "self" with " inner"):
```python
edited_text = replace_words(lowercase_text, "self", "inner")
```

5. **Print the edited text:**
```python
print(edited_text)
```
Now we have a Python program that applies initial self-edits to the input text!
