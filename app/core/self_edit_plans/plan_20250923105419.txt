```python
def extract_question_info(question):
    return {
        'question_id': question['question_id'],
        'title': question.get('title', ''),
        'tags': [tag for tag in question['tags'] if tag],
        'owner': {'name': question['owner']['display_name'], 'reputation': question['owner']['reputation']},
        'score': question['score']
    }
```
We'll define a function `extract_question_info` to extract relevant information from each question dictionary. This function will return a new dictionary containing the question ID, title (defaulting to an empty string if missing), tags (filtered to remove any empty strings), owner name and reputation, and score.

**Step 4: Apply the extraction function to each question**
```python
question_info_list = [extract_question_info(question) for question in data['items']]
```
We'll use a list comprehension to apply the `extract_question_info` function to each question dictionary in the `data` dictionary. This will give us a list of dictionaries containing the extracted information.

**Step 5: Print the extracted question information**
