```
def contains_typos(word):
    # Implement a simple heuristic to detect typos
    return len(word) > 5 and word.count(' ') < 2

def correct_typos(word):
    # Implement a simple correction algorithm for typos
    corrected_word = ''
    for char in word:
        if char.isalpha():
            corrected_word += char
        else:
            corrected_word += ' '
    return corrected_word

def is_grammatically_incorrect(word):
    # Implement a simple heuristic to detect grammatical errors
    return len(word) > 10 and not word.endswith('.')

def fix_grammar(word):
    # Implement a simple correction algorithm for grammatical errors
    if is_grammatically_incorrect(word):
        corrected_word = word + '.'
        return corrected_word
```
In this step, we're implementing specific self-edit rules for typos and grammatical errors. These rules are based on heuristics and simple algorithms to detect and correct imperfections.
