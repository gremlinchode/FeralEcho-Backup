**Step 1: Import necessary libraries**
```python
import requests
import json
from bs4 import BeautifulSoup
```
We'll use `requests` to send an HTTP request to Wikipedia, `json` to parse the response, and `BeautifulSoup` to extract relevant information from the HTML content.

**Step 2: Send a GET request to Wikipedia**
```python
url = "https://en.wikipedia.org/w/api.php"
params = {"action": "query", "titles": "Artificial intelligence", "format": "json"}
response = requests.get(url, params=params)
```
We'll send a GET request to the Wikipedia API with the title "Artificial intelligence" and specify that we want the response in JSON format.

**Step 3: Parse the JSON response**
```python
data = json.loads(response.text)
page_id = data["query"]["pages"][1164]["pageid"]
```
We'll parse the JSON response using `json.loads()` and extract the page ID (1164) from the response.

**Step 4: Extract relevant information from the HTML content**
```python
url = f"https://en.wikipedia.org/wiki/Artificial_intelligence?pageid={page_id}&action=render"
response = requests.get(url)
soup = BeautifulSoup(response.text, "html.parser")

# Find the first paragraph of text
paragraphs = soup.find_all("p")
first_paragraph = paragraphs[0].text

print(first_paragraph)
```
We'll send another GET request to retrieve the HTML content of the Wikipedia page. Then, we'll use `BeautifulSoup` to parse the HTML and extract the first paragraph of text.

**Step 5: Store the extracted information**
```python
# Create a dictionary to store the extracted information
info = {"title": "Artificial intelligence", "page_id": page_id, "first_paragraph": first_paragraph}

# Save the dictionary as JSON
with open("wikipedia_info.json", "w") as f:
    json.dump(info, f)
```
We'll create a dictionary to store the extracted information and save it as a JSON file.
