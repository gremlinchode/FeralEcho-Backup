code = ... # assume this is the parsed code (e.g., a string)

**Step 4: Extract Function and Class Information**
To extract information about functions and classes, we'll need to traverse the Abstract Syntax Tree. We can use recursive function calls to achieve this.
```python
def get_functions(tree):
    functions = []
    for node in ast.walk(tree):
        if isinstance(node, ast.FunctionDef):
            functions.append(node.name)
    return functions

def get_classes(tree):
    classes = []
    for node in ast.walk(tree):
        if isinstance(node, ast.ClassDef):
            classes.append(node.name)
    return classes
```
**Step 5: Extract Import Statements**
To extract import statements, we'll need to traverse the Abstract Syntax Tree again. This time, we're looking for `ast.Import` or `ast.ImportFrom` nodes.
```python
def get_imports(tree):
    imports = []
    for node in ast.walk(tree):
        if isinstance(node, ast.Import):
            imports.extend([n.name for n in node.names])
        elif isinstance(node, ast.ImportFrom):
            imports.append(node.module)
    return imports
```
**Step 6: Compile the Results**
Finally, let's compile the results from our analysis into a single output string.
```python
def compile_results(functions, classes, imports):
    result = "Parsed code successfully. Functions: {}, Classes: {}, Imports: {}".format(
        ", ".join(functions), ", ".join(classes), ", ".join(imports)
    )
    return result

# Run the analysis
functions = get_functions(tree)
classes = get_classes(tree)
imports = get_imports(tree)

result = compile_results(functions, classes, imports)
print(result)
```
