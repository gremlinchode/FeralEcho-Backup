We'll use `requests` to fetch the Wikipedia page data, `json` to parse the response, and `BeautifulSoup` to extract relevant information from the HTML.

**Step 2: Fetch the Wikipedia page data**
```python
url = "https://en.wikipedia.org/w/api.php"
params = {"action": "query", "titles": "Artificial_intelligence", "format": "json"}
response = requests.get(url, params=params)
data = json.loads(response.text)
```
We'll send a GET request to the Wikipedia API with the necessary parameters (title and format) and store the response in `data`.

**Step 3: Extract relevant information from the page data**
```python
page_id = data["query"]["pages"][0]["pageid"]

display_title = data["query"]["pages"][0]["displaytitle"]

print(f"Page ID: {page_id}, Revision ID: {revision_id}, Title: {title}, Display Title: {display_title}")
```
