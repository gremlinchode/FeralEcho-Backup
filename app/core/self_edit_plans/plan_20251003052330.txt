```python
import torch
from transformers import AutoModelForSequenceClassification, AutoTokenizer

# Load pre-trained model and tokenizer
model = AutoModelForSequenceClassification.from_pretrained('distilbert-base-uncased')
tokenizer = AutoTokenizer.from_pretrained('distilbert-base-uncased')

def analyze_text(text):
    # Preprocess text using the tokenizer
    inputs = tokenizer.encode_plus(
        text,
        max_length=512,
        padding='max_length',
        truncation=True,
        return_attention_mask=True,
        return_tensors='pt'
    )
    
    # Perform analysis using the pre-trained model
    outputs = model(**inputs)
    results = torch.argmax(outputs.logits, dim=-1).tolist()
    
    return results
```
**Step 5:** Integrate everything
Now that we have individual components, let's tie them together into a cohesive script. We'll read input files, create output directories, and perform text analysis using the pre-trained model.
```python
def main():
    # Get command-line arguments
    input_file = args.input_file
    output_dir = args.output_dir
    
    # Read input file
    input_text = read_input_file(input_file)
    
    # Perform text analysis
    results = analyze_text(input_text)
    
    # Create output directory if it doesn't exist
    create_output_dir(output_dir)
    
    # Save analysis results to the output directory
    with open(os.path.join(output_dir, 'results.txt'), 'w') as f:
        f.write(str(results))
```
