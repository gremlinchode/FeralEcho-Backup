Here's the full code:
```python
import wikipedia
from bs4 import BeautifulSoup

page_data = wikipedia.page("Artificial intelligence")
type = page_data["type"]
title = page_data["title"]
display_title = page_data["displaytitle"]

soup = BeautifulSoup(page_data.content, 'html.parser')
namespace_id = soup.find("span", {"class": "mw-page-title-main"}).get("id")
wikibase_item = soup.find("span", {"class": "mw-page-title-main"}).text

data_dict = {
    'type': type,
    'title': title,
    'display_title': display_title,
    'namespace_id': namespace_id,
    'wikibase_item': wikibase_item
}

print(data_dict)
```
