**Step 1: Import necessary modules**
We need to import the `os` and `stat` modules to work with file permissions.
```python
import os
import stat
```
**Step 2: Define the `check_permissions` function**

This is the main function we're interested in. Let's define it as follows:
```python
def check_permissions(file_path):
    """
    Check the permissions of a given file.

    Args:
        file_path (str): The path to the file

    Returns:
        A dictionary containing the file's permission details
    """
```
**Step 3: Use `os.stat` to get file statistics**

We'll use the `os.stat` function to retrieve information about the file, including its permissions.
```python
stat_info = os.stat(file_path)
```
**Step 4: Extract relevant permission details**

From the `stat_info`, we can extract the following permission-related values:

* `st_mode`: The file's mode (permissions) as an integer value
* `st_uid` and `st_gid`: The owner and group IDs, respectively

Let's store these in a dictionary:
```python
permission_dict = {
    'mode': stat_info.st_mode,
    'owner_id': stat_info.st_uid,
    'group_id': stat_info.st_gid
}
```
**Step 5: Convert mode to readable permissions**

We can convert the `st_mode` value to a human-readable string representation of the file's permissions using the following code:
```python
permission_dict['mode'] = oct(stat_info.st_mode)
```
This will give us a string like `'644'` or `'755'`, indicating the file's permission bits.

**Step 6: Return the permission dictionary**

Finally, we'll return the `permission_dict` containing the file's permission details:
```python
return permission_dict
```
