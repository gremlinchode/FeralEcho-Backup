**Step 1: Import required libraries**
```python
import requests
import json
from bs4 import BeautifulSoup
```
We'll use `requests` to send an HTTP request to Wikipedia, `json` to parse the response, and `BeautifulSoup` to parse the HTML content.

**Step 2: Send a GET request to Wikipedia's API**
```python
url = 'https://en.wikipedia.org/w/api.php'
params = {'action': 'query', 'titles': 'Artificial intelligence', 'format': 'json'}
response = requests.get(url, params=params)
```
We'll send a GET request to the Wikipedia API with the `action=query` and `titles=Artificial intelligence` parameters. The response will be in JSON format.

**Step 3: Parse the JSON response**
```python
data = json.loads(response.text)
page_id = data['query']['pages']['1164']
```
We'll use the `json.loads()` function to parse the JSON response and extract the page ID (`1164`) from the response.

**Step 4: Extract relevant information from the Wikipedia page**
```python
soup = BeautifulSoup(response.content, 'html.parser')
title = soup.find('span', {'class': 'mw-page-title-main'}).text
description = soup.find('div', {'id': 'mw-content-text'}).text
```
We'll use `BeautifulSoup` to parse the HTML content of the Wikipedia page and extract the title (`<span class="mw-page-title-main">`) and description (`<div id="mw-content-text">`) sections.

**Step 5: Store the extracted information in a dictionary**
```python
wikipedia_data = {'title': title, 'description': description}
```
We'll store the extracted title and description in a Python dictionary called `wikipedia_data`.

**Step 6: Print the extracted information**
```python
print(wikipedia_data)
```
Finally, we'll print the extracted information to the console.
