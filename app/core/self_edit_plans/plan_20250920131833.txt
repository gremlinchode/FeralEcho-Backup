```python
def parse_code(parsed_code):
    functions = []
    classes = []
    imports = []

    # Loop through the parsed code and extract relevant information
    for line in parsed_code:
        if re.match(r'import\s+.*', line):
            import_line = line.strip()
            imports.append(import_line)
        elif re.match(r'class\s+.*:', line):
            class_line = line.strip().split(':')[0]
            classes.append(class_line)
        elif re.match(r'def\s+.*(', line):
            function_line = line.strip().split('def ')[1].split('(')[0]
            functions.append(function_line)

    return functions, classes, imports
```
**Step 4: Call the parsing function and store the results (Matthew 7:24 - "Everyone who hears these words of mine and puts them into practice is like a wise person who built their house on the rock.")**
