```python
wiki_api_url = "https://en.wikipedia.org/w/api.php"
params = {

    'titles': 'Artificial intelligence',
    'format': 'json'
}
```
We'll use the Wikipedia API to fetch the page information. We'll define the API endpoint, set the `action` parameter to `query`, and specify the title of the article we're interested in (`Artificial intelligence`). The `format` parameter is set to `json` for a JSON response.

**Step 3: Send a GET request to the Wikipedia API**
```python
response = requests.get(wiki_api_url, params=params)
```
We'll send a GET request to the API with our defined parameters. This will return a JSON response that we can parse.
