**Step 5: Define a function to extract weather data from Wikipedia**
```python
def get_weather_data(article_title):
    try:
        wiki_article = wikipedia.page(article_title)
        weather_text = wiki_article.text.lower()
        for line in weather_text.split('\n'):
            if "weather" in line or "climat" in line:
                return line.strip().split(':')[1].strip()
    except wikipedia.exceptions.DisambigationError as e:
        print(f"Error: {e}")
    return None
```
This function takes an article title and attempts to extract relevant weather information from the Wikipedia page. We'll use this function to determine the current weather conditions.

**Step 6: Get weather data for Artificial Intelligence**
```python
weather_article_title = "Artificial intelligence"
current_weather = get_weather_data(weather_article_title)
```
We'll pass in the article title "Artificial intelligence" and store the resulting weather information in `current_weather`.
