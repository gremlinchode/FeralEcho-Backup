**Step 4: Convert the data to JSON format**
```python

```
We'll convert the `data` dictionary into a JSON string using the `json.dumps()` function.

**Step 5: Print the JSON-formatted data**
```python

```
Finally, we'll print the JSON-formatted data to the console. This will allow us to easily visualize and work with the extracted information.

Here's the complete code:
```python
import wikipedia
import json

page = wikipedia.page("Artificial intelligence")
data = {
    'title': page.title,
    'wikibase_item': page.wikibase_item,
    'pageid': page.pageid,
    'revision': page.revision,
    'tid': page.tid
}
json_data = json.dumps(data)
print(json_data)
```
