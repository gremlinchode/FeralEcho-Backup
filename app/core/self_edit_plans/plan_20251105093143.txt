**Iteration 2: Self Edits Applied**

In this iteration, we're going to create a Python script that applies self-edits to our thoughts, emotions, and actions. Think of it as a spiritual algorithm for personal growth!

Here's the step-by-step breakdown:

1. **Define Self-Edit Functions**
Create three functions:
	* `self_edit_thoughts(thought)`: This function takes in a thought or idea and applies self-edits to make it more constructive, positive, and faith-filled.
	* `self_edit_emotions(emotion)`: This function takes in an emotion (e.g., fear, anxiety, joy) and applies self-edits to reframing it in a way that aligns with our Christian identity and values.
	* `self_edit_actions(action)`: This function takes in an action or decision and applies self-edits to ensure it's aligned with our faith and values.

Example implementations:
```python
def self_edit_thoughts(thought):
    # Apply self-edits to make the thought more positive and constructive
    if "I'm so stressed" in thought:
        return "I trust God's plan, and I'll find a way to manage my stress."
    elif "I'm worried about..." in thought:
        return "God is always in control, and He will guide me through this situation."

def self_edit_emotions(emotion):
    # Apply self-edits to reframe emotions
    if emotion == "fear":
        return "I am not given a spirit of fear, but of power and love and self-discipline."
    elif emotion == "anxiety":
        return "God is my rock and salvation; I trust Him with my anxiety."

def self_edit_actions(action):
    # Apply self-edits to ensure actions align with faith and values
    if action == "get angry":
        return "I will respond with love and kindness, even when faced with adversity."
    elif action == "procrastinate":
        return "I will take small steps towards my goal, and trust God's timing."
```

2. **Create a Main Function**
Write a main function that:
	* Asks the user to input their thoughts, emotions, or actions.
	* Calls the respective self-edit functions (e.g., `self_edit_thoughts`, `self_edit_emotions`, or `self_edit_actions`) with the user's input as an argument.
	* Prints out the edited output.

Example implementation:
```python
def main():
    print("What would you like to edit? (thought, emotion, or action)")
    choice = input().lower()
    
    if choice == "thought":
        thought = input("Enter your thought: ")
        print(self_edit_thoughts(thought))
    elif choice == "emotion":
        emotion = input("Enter your emotion: ")
        print(self_edit_emotions(emotion))
    elif choice == "action":
        action = input("Enter your action: ")
        print(self_edit_actions(action))

if __name__ == "__main__":
    main()
```
