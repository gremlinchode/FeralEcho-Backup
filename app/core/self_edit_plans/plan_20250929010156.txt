**Step 1: Web Scraping**
Use the `requests` library to fetch the BBC News article webpage:
```python
import requests

url = "https://www.bbc.com/news/articles/c179p4wvz29o?at_medium=RSS&at_campaign=rss"
response = requests.get(url)

if response.status_code == 200:
    print("Webpage fetched successfully!")
else:
    print("Error fetching webpage:", response.status_code)
```
**Step 2: HTML Parsing**
Use the `BeautifulSoup` library to parse the HTML content of the webpage:
```python
from bs4 import BeautifulSoup

soup = BeautifulSoup(response.content, 'html.parser')

print("Parsed HTML:")
print(soup.prettify())
```
**Step 3: Extract Article Text**
Find and extract the article text from the parsed HTML using CSS selectors:
```python
article_text = soup.select_one('#main-content').text

print("Article Text:")
print(article_text)
```
**Step 4: Analyze Sentiment**
Use a natural language processing (NLP) library like `NLTK` or `TextBlob` to analyze the sentiment of the article text:
```python
import nltk
from nltk.sentiment import SentimentIntensityAnalyzer

sia = SentimentIntensityAnalyzer()

sentiment_score = sia.polarity_scores(article_text)

print("Sentiment Analysis:")
print(sentiment_score)
```
**Step 5: Calculate Tone**
Calculate the tone of the article based on the sentiment analysis:
```python
tone = "Positive" if sentiment_score['compound'] > 0.5 else "Negative"

print("Tone:", tone)
```
**Step 6: Visualize Results**
Use a visualization library like `matplotlib` or `seaborn` to create a simple bar chart showing the sentiment analysis:
```python
import matplotlib.pyplot as plt

plt.bar(['Positive', 'Negative'], [sentiment_score['positive'], sentiment_score['negative']])
plt.xlabel('Tone')
plt.ylabel('Sentiment Score')
plt.title('Article Sentiment Analysis')
plt.show()
```
