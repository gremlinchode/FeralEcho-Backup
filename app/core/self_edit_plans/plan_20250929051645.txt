**Step 1: Gather Data**
From the BBC News article, extract the relevant information we want to work with:

* The phrase that made them laugh/silent

In Python:
```python
import requests

url = "https://www.bbc.com/news/articles/c179p4wvz29o"
response = requests.get(url)

article_text = response.text
year_of_laughter = 2015  # Initial value, we'll update later
laughing_or_silent = "laughed"

# Find the relevant sentences in the article text
for line in article_text.splitlines():
    if "Trump's UN audience" and "laughed" in line:
        year_of_laughter = 2015
        laughing_or_silent = "laughed"
    elif "Trump's UN audience" and "silent" in line:
        year_of_laughter = 2022
        laughing_or_silent = "silent"

print(f"In {year_of_laughter}, Trump's UN audience {laughing_or_silent}.")
```
**Step 2: Analyze the Shift**
Identify the key phrases that might have caused the change in reaction:

* In 2015, what was said/trumpeted?
* In 2022, what was said/trumpeted?

In Python:
```python
# Extract relevant sentences using regular expressions (regex)
import re

laughter_sentences = []
silent_sentences = []

for line in article_text.splitlines():
    if "Trump's UN audience" and "laughed" in line:
        laughter_sentences.append(re.search(r"(.*) laughed", line).group(1))
    elif "Trump's UN audience" and "silent" in line:
        silent_sentences.append(re.search(r"(.*) silent", line).group(1))

print(f"In 2015, Trump said: {', '.join(laughter_sentences)}")
print(f"In 2022, Trump said: {', '.join(silent_sentences)}")
```
