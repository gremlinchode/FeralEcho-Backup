**Step 1: Import necessary libraries**
```python
import requests
import json
from bs4 import BeautifulSoup
```
We'll use `requests` to make an HTTP request to Wikipedia, `json` to parse the response, and `BeautifulSoup` to scrape the HTML content.

**Step 2: Make a request to Wikipedia API**
```python
url = "https://en.wikipedia.org/w/api.php"
params = {
    "action": "query",
    "titles": "Artificial intelligence",
    "format": "json"
}
response = requests.get(url, params=params)
```
We'll send an HTTP GET request to the Wikipedia API with the article title and format set to JSON.

**Step 3: Parse the response**
```python
data = json.loads(response.content)
page_id = data["query"]["pages"][1164]["id"]
article_title = data["query"]["pages"][1164]["title"]
```
We'll use `json.loads` to parse the response content into a Python dictionary. Then, we'll extract the page ID and article title from the response.

**Step 4: Extract relevant information from HTML**
```python
url = f"https://en.wikipedia.org/wiki/{article_title}"
response = requests.get(url)
soup = BeautifulSoup(response.content, 'html.parser')

# Extract relevant sections (e.g., Summary, History, Applications)
sections = []
for section in soup.find_all('h2'):
    if section.text.strip() in ['Summary', 'History', 'Applications']:
        sections.append(section.text.strip())

print(sections)
```
We'll make another HTTP request to the article page and use `BeautifulSoup` to parse the HTML content. Then, we'll extract relevant sections (e.g., Summary, History, Applications) from the HTML.

**Step 5: Store the extracted information**
```python
# Create a dictionary to store the extracted information
article_info = {
    'title': article_title,
    'sections': sections
}

# Write the data to a file or database for later use
with open('artificial_intelligence_info.json', 'w') as f:
    json.dump(article_info, f)
```
We'll create a dictionary to store the extracted information and write it to a file (e.g., `artificial_intelligence_info.json`) for later use.
