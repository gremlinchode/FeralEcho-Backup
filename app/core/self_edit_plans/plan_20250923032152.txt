**Step 1: Import necessary libraries**
```
import json
import requests
```
We'll need these libraries to work with JSON data and send HTTP requests.

**Step 2: Define the API endpoint and parameters**
```
api_endpoint = "https://api.stackexchange.com/2.2/questions"
params = {"order": "desc", "sort": "activity", "site": "python"}
```
We'll use the Stack Exchange API to fetch questions related to Python programming.

**Step 3: Send a GET request to the API**
```
response = requests.get(api_endpoint, params=params)
```
This will retrieve a list of questions in JSON format.

**Step 4: Parse the JSON response**
```
data = json.loads(response.content.decode("utf-8"))
```
We'll convert the JSON response into a Python dictionary for easier manipulation.

**Step 5: Extract relevant information from each question**
```
for item in data["items"]:
    # Get the question ID, owner's display name, and score
    question_id = item["question_id"]
    owner_display_name = item["owner"]["display_name"]
    score = item["score"]

    print(f"Question {question_id} by {owner_display_name} has a score of {score}")
```
We'll iterate through each question in the JSON response and extract relevant information, such as the question ID, owner's display name, and score.

**Step 6: Filter out questions that are answered or have low scores**
```
answered_questions = []
low_score_questions = []

for item in data["items"]:
    if item["is_answered"] or item["score"] < 10:
        continue
    answered_questions.append(item)
    low_score_questions.append(item)

print(f"Unanswered questions: {len(answered_questions)}")
print(f"Low-scoring questions: {len(low_score_questions)}")
```
We'll filter out questions that are already answered or have a score of less than 10. This will help us focus on questions that need more attention.
