```python
def parse_item(item):
    result = {}
    result['owner'] = {
        'account_id': item['owner']['account_id'],
        'reputation': item['owner']['reputation'],
        'user_id': item['owner']['user_id'],
        'display_name': item['owner']['display_name']
    }
    result['tags'] = item['tags']
    return result
```
This function takes an `item` dictionary and extracts relevant information to create a new, simplified dictionary. We'll use this function to process each item in the list.

**Step 4: Process the item list**
```python
parsed_items = [parse_item(item) for item in item_list]
```
We'll apply our `parse_item` function to each item in the `item_list` and store the results in a new list, `parsed_items`.
