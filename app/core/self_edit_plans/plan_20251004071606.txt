**Step 4: Check permissions using `stat.S_IMODE`**
```python
def check_permissions(path):
    try:
        file_stats = os.stat(path)
    except FileNotFoundError:
        return "File not found!"
    except PermissionError:
        return "Access denied!"

    mode = file_stats.st_mode & stat.S_IMODE

    if mode == 0o755:  # owner has read, write, and execute
        return "Owner has permissions"
    elif mode == 0o750:  # owner has read and execute, group has read and execute
        return "Owner has some permissions, group also has some"
    else:
        return "Permissions unknown or unclear"
```
Now we're getting to the meat of the matter! We'll use `stat.S_IMODE` to extract the file's permission mode. Depending on the mode, we'll return a message indicating who has what kind of access.
