**Step 3: Extracting Relevant Information**
```
functions = []  # Initialize empty list for functions
classes = []  # Initialize empty list for classes
imports = []  # Initialize empty list for imports

for node in parsed_code.body:
    if isinstance(node, ast.FunctionDef):
        functions.append(node.name)  # Add function name to the list
    elif isinstance(node, ast.ClassDef):
        classes.append(node.name)  # Add class name to the list
    elif isinstance(node, ast.Import):
        for alias in node.names:
            imports.append(alias.name)  # Add imported module name to the list

print(f"Functions: {functions}, Classes: {classes}, Imports: {imports}")
```
In this step, we iterate through the parsed code's AST nodes and extract relevant information about functions, classes, and imports. We use Python's built-in `isinstance` function to check the type of each node and append the necessary information to our lists.

**Step 4: Organizing and Displaying Results**
```
result_dict = collections.OrderedDict({
    "Functions": functions,
    "Classes": classes,
    "Imports": imports
})

print(result_dict)
```
Finally, we create an ordered dictionary (using `collections.OrderedDict`) to store our results. We then print the dictionary in a human-readable format.

There you have it! By following these sequential steps, we've successfully analyzed and parsed the given code, extracting relevant information about functions, classes, and imports.
