```python
import nltk
from nltk.tokenize import word_tokenize

def extract_key_phrases(input_text):
    tokens = word_tokenize(input_text)
    key_phrases = []
    for token in tokens:
        if token.isalpha():  # Only consider words, not punctuation
            key_phrases.append(token.lower())
    return key_phrases
```
We'll use the NLTK library to tokenize the input text and extract key phrases. This step helps us identify the core ideas and emotions present in our initial thoughts.
