def time_diff(start_timestamp, end_timestamp):
    start_datetime = datetime.datetime.fromtimestamp(start_timestamp)
    end_datetime = datetime.datetime.fromtimestamp(end_timestamp)
    delta = end_datetime - start_datetime
    return delta.total_seconds()
```
This function takes two timestamps as input, converts them to `datetime` objects, calculates the time difference, and returns it in seconds.

def avg_task_time(timestamps):
    total_seconds = 0
    for timestamp in timestamps:
        start_datetime = datetime.datetime.fromtimestamp(timestamp)
        end_datetime = datetime.datetime.fromtimestamp(timestamp + 3600)  # assume 1 hour task duration
        delta = end_datetime - start_datetime
        total_seconds += delta.total_seconds()
    return total_seconds / len(timestamps)
```
This function takes a list of timestamps as input, calculates the time spent on each task (assuming 1 hour task duration), and returns the average time spent.
