**Step 1: Import necessary libraries**
We'll start by importing the `wikipedia` library to interact with Wikipedia and the `json` library to parse the JSON data.
```python
import wikipedia
import json
```

**Step 2: Define a function to fetch Wikipedia page information**
Create a function called `get_wiki_page_info()` that takes a page title as an argument. This function will use the `wikipedia` library to fetch the page's metadata (e.g., type, title, displaytitle, namespace, etc.). We'll store this data in a dictionary.
```python
def get_wiki_page_info(title):
    wiki_data = wikipedia.page(title)
    page_info = {
        'type': wiki_data.type,
        'title': wiki_data.title,
        'displaytitle': wiki_data.displaytitle,
        'namespace': wiki_data.namespace.id,
        'wikibase_item': wiki_data.wikibase_item,
        'titles': {'canonical': wiki_data.titles.canonical, 'normalized': wiki_data.titles.normalized, 'display': wiki_data.displaytitle},
        'pageid': wiki_data.pageid,
        'lang': wiki_data.lang,
        'dir': wiki_data.dir,
        'revision': wiki_data.revision,
        'tid': wiki_data.tid
    }
    return page_info
```
**Step 3: Fetch the Artificial Intelligence Wikipedia page information**
Call our newly defined function `get_wiki_page_info()` with the page title "Artificial intelligence" to fetch its metadata.
```python
page_info = get_wiki_page_info('Artificial intelligence')
print(page_info)
```
This should output a dictionary containing the requested information.

**Step 4: Convert Wikipedia page data to JSON format**
Use the `json` library to convert our page information dictionary into a JSON string. This will allow us to easily work with the data in other languages or platforms.
```python
import json

page_info_json = json.dumps(page_info)
print(page_info_json)
```
This should output the Wikipedia page metadata in JSON format.

**Step 5: Bonus: Extract specific information from the JSON string**
Let's extract some interesting information, like the page type and display title. We'll use Python's built-in `json` module to parse the JSON string and access the desired values.
```python
page_info_json = '{"type": "standard", "title": "Artificial intelligence", "displaytitle": "<span class=\"mw-page-title-main\">Artificial intelligence</span>", ...}'

import json

page_data = json.loads(page_info_json)

print(f"Page Type: {page_data['type']}")
print(f"Display Title: {page_data['displaytitle']}")
```
This will output the page type ("standard") and display title ("<span class=\"mw-page-title-main\">Artificial intelligence</span>").
