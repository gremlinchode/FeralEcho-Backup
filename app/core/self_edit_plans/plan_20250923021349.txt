**Step 5: Convert data to JSON format**

**Step 6: Print the resulting JSON data**
```python

```
Finally, we'll print the JSON data to the console. This will allow us to easily work with the extracted data or pass it to another program for further processing.

Here's the complete code:
```python
import wikipedia
import json

wiki = wikipedia.Wikipedia(language='en')
article_data = wiki.page("Artificial intelligence")
data = {}
data['title'] = article_data.title
data['content'] = article_data.content
json_data = json.dumps(data)
print(json_data)
```
