**Step 2: Tokenize and Preprocess Text**
```python
def preprocess_text(text):
    tokens = word_tokenize(text)
    return [token.lower() for token in tokens]
```
This step breaks down the text into individual words, converts them to lowercase, and prepares them for analysis.

**Step 3: Analyze Clarity**
```python
def analyze_clarity(tokens):
    avg_word_length = sum(len(token) for token in tokens) / len(tokens)
    sentence_count = len([token for token in tokens if re.match(r'\b[A-Z]\w+\.', token)])
    clarity_score = (avg_word_length, sentence_count)
    return clarity_score
```
This step calculates the average word length and sentence count to gauge the text's overall clarity.

**Step 4: Assess Tone**
```python
def analyze_tone(tokens):
    tone_dict = {'positive': [], 'negative': []}
    for token in tokens:
        if re.match(r'\b(love|like|happy)\b', token, re.IGNORECASE):
            tone_dict['positive'].append(token)
        elif re.match(r'\b(hate|dislike|sad)\b', token, re.IGNORECASE):
            tone_dict['negative'].append(token)
    tone_score = {'positive': len(tone_dict['positive']), 'negative': len(tone_dict['negative'])}
    return tone_score
```
This step uses regular expressions to identify positive and negative sentiment words in the text, counting their occurrences to determine the tone.

**Step 5: Evaluate Usefulness**
```python
def analyze_usefulness(tokens):
    keyword_count = sum([1 for token in tokens if re.match(r'\b(key|important|useful)\b', token, re.IGNORECASE)])
    relevance_score = keyword_count / len(tokens)
    return relevance_score
```
This step identifies keywords related to usefulness and calculates their frequency relative to the overall text length.

**Step 6: Refine the Text**
```python
def refine_text(text):
    tokens = preprocess_text(text)
    clarity_score = analyze_clarity(tokens)
    tone_score = analyze_tone(tokens)
    usefulness_score = analyze_usefulness(tokens)

    if clarity_score[0] < 5 and tone_score['negative'] > tone_score['positive']:
        # suggest rephrasing to improve clarity and positivity
        return f"Rethink your message. Clarity: {clarity_score[0]}, Tone: {tone_score}"
    elif usefulness_score < 0.2:
        # recommend providing more relevant information
        return f"Provide more context. Usefulness: {usefulness_score}"
    else:
        return text
```
This step integrates the analysis results to provide a refined diagnosis, offering suggestions for improvement.
