3. **Implement a simple spell-checker using regular expressions:**
```python
import re

# Define a dictionary of common misspellings (e.g., "teh" -> "the")
misspellings = {
    "teh": "the",
    "ur": "your",
    "dont": "don't"
}

def correct_spelling(text):
    for old, new in misspellings.items():
        text = re.sub(re.escape(old), new, text)
    return text
```
4. **Implement a grammar-checker using string manipulation:**
```python
import string

# Define a dictionary of common grammatical errors (e.g., "me" -> "I")
errors = {
    "me": "I",
    "myself": "I"
}

def correct_grammar(text):
    for old, new in errors.items():
        text = text.replace(old, new)
    return text
```
