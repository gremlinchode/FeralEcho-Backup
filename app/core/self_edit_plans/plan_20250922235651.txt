**Step 2: Define a function to fetch the SO question**
```python
def get_so_question(question_id):
    url = f"https://api.stackexchange.com/2.2/questions/{question_id}?order=desc&sort=activity"
    response = requests.get(url)
    return json.loads(response.content)
```
This function takes a `question_id` as input and returns the question data in JSON format.

**Step 3: Define a function to extract relevant information**
```python
def extract_info(question_data):
    owner_name = question_data['items'][0]['owner']['display_name']
    question_score = question_data['items'][0]['score']
    return {'owner_name': owner_name, 'question_score': question_score}
```
This function takes the JSON data as input and extracts the owner's name and the question score.

**Step 4: Call the functions and print the results**
```python

print(f"Question Score: {info_dict['question_score']}")
```
This code calls the `get_so_question` function to fetch the question data, then passes that data to the `extract_info` function to extract the relevant information. Finally, it prints the results.
