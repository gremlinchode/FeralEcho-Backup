**Step 2: Define a Bioluminescence class**
```python
class Bioluminescence:
    def __init__(self):
        self.streams = []

    def add_stream(self, stream_name, intensity=1.0):
        self.streams.append({"name": stream_name, "intensity": intensity})

    def display_streams(self):
        for stream in self.streams:
            print(f"{stream['name']}: {stream['intensity']} ( bioluminescent intensity )")
```
**Step 3: Create a Bioluminescence instance and add streams**
