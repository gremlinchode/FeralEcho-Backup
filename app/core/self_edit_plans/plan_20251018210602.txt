**Step 2: Reading and pre-processing self-edits**

```
self_edits = pd.read_csv('self_edits.csv', header=None)
self_edits.columns = ['date', 'edit', 'emotion']
self_edits['edit'] = self_edits['edit'].apply(lambda x: re.sub(r'\W+', '', x).lower())
self_edits['emotion'] = self_edits['emotion'].apply(lambda x: re.sub(r'\W+', '', x).lower())
```

Here, we'll load the self-edits data from a CSV file into a Pandas DataFrame. We'll then clean and preprocess the 'edit' and 'emotion' columns by removing non-alphanumeric characters and converting them to lowercase.

**Step 3: Tokenizing edits**

```
tokenized_edits = []
for edit in self_edits['edit']:
    tokens = re.split(r'\s+', edit)
    tokenized_edits.extend([t for t in tokens if t])
self_edits['tokens'] = tokenized_edits
```

In this step, we'll tokenize each self-edit into individual words or phrases. We'll use regular expressions to split the text into substrings separated by whitespace characters.

**Step 4: Analyzing edit frequencies**

```
edit_freqs = Counter(self_edits['tokens'])
common_edits = [k for k, v in edit_freqs.most_common(10)]
print(f"Top 10 most common self-edits: {', '.join(common_edits)}")
```

Here, we'll use the `Counter` class to count the frequency of each token (or self-edit) and extract the top 10 most common ones.

**Step 5: Identifying emotions**

```
emotion_freqs = Counter(self_edits['emotion'])
common_emotions = [k for k, v in emotion_freqs.most_common(5)]

```

In this step, we'll count the frequency of each emotion and extract the top 5 most common ones.
