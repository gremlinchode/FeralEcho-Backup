**Step 1: Import necessary libraries**
```python
import json
import requests
```
We'll need `json` to parse the JSON data from StackOverflow and `requests` to make API calls.

**Step 2: Define a function to fetch SO questions**
```python
def get_so_questions(tag, page=0):
    url = f"https://api.stackexchange.com/2.2/questions?page={page}&pagesize=100&order=desc&sort=activity&tagged={tag}"
    response = requests.get(url)
    return json.loads(response.content)["items"]
```
This function takes a tag (e.g., "python", "qt", etc.) and an optional page number (default is 0). It constructs the API URL, makes the GET request, and returns the JSON data.

**Step 3: Define a function to extract relevant information from each question**
```python
def process_so_question(question):
    owner = question["owner"]
    return {
        "tags": question["tags"],
        "owner_id": owner["user_id"],
        "reputation": owner["reputation"],
        "display_name": owner["display_name"],
        "link": owner["link"],
        "is_answered": question["is_answered"],
        "view_count": question["view_count"],
        "answer_count": question["answer_count"],
        "score": question["score"],
    }
```
This function takes a SO question dictionary and extracts relevant information (tags, owner ID, reputation, display name, link, is answered, view count, answer count, and score).

**Step 4: Loop through questions and process each one**
```python
def fetch_so_questions(tag):
    questions = []
    page = 0
    while True:
        question_list = get_so_questions(tag, page)
        for question in question_list:
            processed_question = process_so_question(question)
            questions.append(processed_question)
        if len(question_list) < 100:  # API returns up to 100 questions per page
            break
        page += 1
    return questions
```
This function takes a tag and loops through the SO questions, processing each one using `process_so_question`. It keeps track of the current page number and breaks when the API returns fewer than 100 questions (indicating the end of the question list).

**Step 5: Test the functions**
```python

```
