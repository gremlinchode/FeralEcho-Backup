**Step 5: Analyzing the JSON data (optional)**
```python
with open('ai_article.json', 'r') as f:
    ai_data = json.load(f)

# Example analysis: counting mentions of specific terms
term_counts = {}
for paragraph in ai_data['text'].split('\n'):
    for word in paragraph.split():
        if word.lower() in ['machine', 'learning', 'artificial']:
            term_counts[word] = term_counts.get(word, 0) + 1

print(term_counts)
```
