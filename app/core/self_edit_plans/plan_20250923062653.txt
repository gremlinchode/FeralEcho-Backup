**Step 1: Import necessary libraries**
```python
import requests
import json
from bs4 import BeautifulSoup
```
We'll use `requests` to fetch the Wikipedia page data, `json` to parse the response, and `BeautifulSoup` to extract relevant information from the HTML.

**Step 2: Define the API endpoint and parameters**
```python
url = "https://en.wikipedia.org/w/api.php"
params = {
    'action': 'query',
    'format': 'json',
    'titles': 'Artificial intelligence'
}
```
We'll use the Wikipedia API to fetch the page data. The `action` parameter specifies what action we want to perform (in this case, a query), and `format` sets the response format to JSON. We're searching for the page titled "Artificial intelligence".

**Step 3: Send the request and get the response**
```python
response = requests.get(url, params=params)
data = json.loads(response.text)
```
We send the request to the API using `requests.get()` and store the response as a JSON object using `json.loads()`.

**Step 4: Extract relevant data from the response**
```python
page_id = data['query']['pages'][0]['id']
page_title = data['query']['pages'][0]['title']
```
We extract the page ID and title from the API response. We're interested in the first page returned, as we only searched for one page.

**Step 5: Parse the Wikipedia page HTML using BeautifulSoup**
```python
soup = BeautifulSoup(data['query']['pages'][0]['extract'], 'html.parser')
```
We use `BeautifulSoup` to parse the extracted page content (the HTML) and create a beautiful soup object.

**Step 6: Extract relevant information from the parsed HTML**
```python
# Find all paragraphs
paragraphs = soup.find_all('p')

# Extract text from each paragraph
article_text = []
for paragraph in paragraphs:
    article_text.append(paragraph.text)

# Join the text into one string
article_summary = ' '.join(article_text)
```
We extract all paragraphs from the parsed HTML, then extract the text from each paragraph. Finally, we join the text into a single string, which will serve as our summary of the Wikipedia page.

**Step 7: Store the extracted data**
```python
# Store the page ID, title, and summary in a dictionary
wiki_data = {
    'page_id': page_id,
    'title': page_title,
    'summary': article_summary
}
```
We store the extracted data (page ID, title, and summary) in a dictionary called `wiki_data`.

And that's it! With these sequential Python steps, we've successfully scraped the Wikipedia AI page and extracted relevant information.
