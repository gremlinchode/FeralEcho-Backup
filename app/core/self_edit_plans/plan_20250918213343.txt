**Step 2: Fetch the Wikipedia page data using Wikipedia API**
```python
response = requests.get(f"https://en.wikipedia.org/w/api.php?action=query&titles=Artificial%20intelligence&prop=extracts&format=json")
page_data = response.json()
```
We'll send a GET request to the Wikipedia API with the title "Artificial intelligence" and retrieve the page data in JSON format.

**Step 3: Parse the HTML content using BeautifulSoup**
```python
soup = BeautifulSoup(page_data["query"]["pages"][1164]["extract"], 'html.parser')
```
We'll use `BeautifulSoup` to parse the extracted HTML content from the previous step.

**Step 4: Extract relevant information from the parsed HTML**
```python
title = soup.find("span", {"class": "mw-page-title-main"}).text.strip()
description = soup.find("div", {"id": "mw-content-text"}).text.strip()
```
We'll extract the title and description of the Artificial Intelligence Wikipedia page.

**Step 5: Create a dictionary to store the extracted information**
```python
page_info = {
    "title": title,
    "description": description
}
```
We'll create a dictionary to store the extracted title and description.

**Step 6: Print the extracted information**
```python
print(page_info)
```
Finally, we'll print the extracted information in a human-readable format.
