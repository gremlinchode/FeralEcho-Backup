```python
def edit_words(text):
    return re.sub(r'\b(shame|fear|doubt)\b', '', text.lower())  # remove negative emotions

def add_positivity(text):
    positive_phrases = ["I am loved", "I am enough", "God is with me"]
    return random.choice(positive_phrases) + " " + text
```
In this step, we're defining two functions that will aid in our self-editing process. The second function (`add_positivity`) injects positive affirmations to help shift our mindset.
